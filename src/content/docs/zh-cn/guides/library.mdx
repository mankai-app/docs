**首页**汇集你的收藏和下载内容。在**书库**中可以浏览和搜索插件提供的内容。

## 收藏和查找喜欢的作品

1. 打开书籍详情，轻点**收藏**。
2. 打开**首页**，在内容源菜单中选择**收藏**。
3. 搜索已收藏的作品，或按状态和内容源筛选。
4. 下拉收藏列表以检查更新。

要取消收藏，请打开书籍详情并轻点**移除**。取消收藏和删除已下载的副本是两个独立操作。

## 找一本书来读

1. 打开**书库**，查看插件提供的列表。
2. 从列表中打开作品。如果有插件支持搜索，也可以使用搜索功能。
3. 打开书籍详情，选择**阅读**、**继续**或某一章节。

要返回最近读过的书籍，请打开**设置 → 历史记录**。即使没有收藏，读过的书籍也会出现在历史记录中。

## 下载章节

1. 从支持下载的内容源打开书籍，轻点下载箭头。
2. 在**选择章节**中展开章节组，选中需要的章节。轻点章节组旁的圆形选择按钮，可一次选中该组中所有可下载的章节。
3. 轻点**下载**。
4. 轻点**首页**上的下载箭头查看进度。失败的任务会显示重试按钮。

## 离线阅读与存储管理

1. 在内容源仍可访问时，等待下载完成。
2. 在首页的内容源菜单中选择**下载**，然后打开书籍。
3. 打开已下载的章节进行离线阅读。

离线副本只包含已经下载的章节。收藏作品不会下载页面。要释放存储空间，请在下载面板中滑动已下载的作品，并确认**移除**。你也可以在下载面板中取消等待中的任务，或重试失败的任务。

## 导出已下载的章节

你可以将选中的已下载章节导出为 **MMA** 或 **PDF**：

- **MMA（Mankai Manga Archive）** 将所有选中的章节组、原始页面图片、书籍元数据和封面打包为一个 `.mma` 文件，导出通常比 PDF 更快。有关归档的详细说明，请参阅 [MMA 格式](/zh-cn/api/mma-format/)。
- **PDF** 为每个选中的章节创建单独的 `.pdf` 文件。选择三个章节会生成三个 PDF 文件。

1. 下载要导出的章节，并等待下载完成。
2. 打开书籍详情，在工具栏或 **•••** 菜单中选择**导出**。导出按钮的图标是带向上箭头的方框。
3. 在**导出格式**中选择 **MMA** 或 **PDF**。
4. 展开章节组，选中需要的章节。轻点章节组旁的圆形选择按钮，可一次选中该组中所有已下载的章节。
5. 轻点**导出**，等待显示**导出完成**。
6. 轻点**分享**，然后选择**存储到“文件”**或其他目标位置。关闭导出面板前，请先保存或分享导出的文件。

导出列表只显示完整下载的章节。如果找不到某个章节，请先完成其下载。你也可以在**首页**的下载面板中长按书籍，然后选择**导出**。
