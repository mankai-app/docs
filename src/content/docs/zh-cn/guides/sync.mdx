同步是可选功能，可在设备间共享受支持的插件及其设置、文件夹连接、收藏和阅读进度。书籍文件和已下载的章节仍需在每台设备上分别准备。

你需要兼容的 HTTP 同步服务，或已经配置好的 Supabase 项目。请使用对应服务的连接信息。

## 选择同步服务

1. 打开**设置 → 同步**。
2. 选择**同步引擎**。如果不需要同步，请保留为**无**。
3. 按照下方对应的步骤完成设置。

### iCloud（即将推出）

iCloud 同步即将推出，目前尚不可用。现在请使用 HTTP 或 Supabase 在设备间同步。

### HTTP

使用 HTTP 同步之前，请先通过以下任一仓库搭建兼容的服务器：

- [Mankai Sync](https://github.com/mankai-app/sync)：专用同步服务器，提供用于管理用户的管理页面。
- [Mankai Server](https://github.com/mankai-app/server)：漫画书库服务器，同时支持收藏和阅读进度同步。

按照所选仓库的设置说明完成部署。请使用服务器的 API 网址（这两个服务器均以 `/api` 结尾）和该服务器上的账户凭据。如果使用已有服务，请向管理员索取这些信息。

1. 选择 **HTTP**，在**服务器 URL**中输入同步服务的 API 网址。
2. 轻点**保存配置**。
3. 在**凭据**中输入用户名和密码。
4. 轻点**登录**。

## 检查每个内容源的同步支持

打开**设置 → 插件**并选择插件，或打开**设置 → 文件夹**并选择文件夹。**同步**部分分别显示内容源设置和漫画记录的同步状态：

| 状态                 | 显示为已启用时                                   |
| -------------------- | ------------------------------------------------ |
| **跨设备同步插件**   | 在其他设备上安装插件，并同步其设置。             |
| **跨设备同步文件夹** | 将文件夹的连接设置同步到其他设备。               |
| **跨设备同步漫画**   | 同步该内容源中漫画的书库记录（收藏）和阅读进度。 |

这些状态会根据内容源的功能自动显示。如果状态为**已禁用**，下方会说明无法同步的原因。

## 同步两台设备

1. 状态显示为**已启用**后，轻点**立即同步**。
2. 确认上次同步时间已成功更新。
3. 在另一台设备上配置相同的服务和账户，然后也轻点**立即同步**。
4. 打开**设置 → 插件**和**设置 → 文件夹**，检查同步恢复的受支持插件和文件夹连接。
5. 手动添加文件系统内容源或没有可用下载网址的插件，并确认另一台设备能够打开相同的书籍。
6. 打开受支持的书籍，并使用**继续**从上次的位置继续阅读。

## 保持内容源标识一致

文件夹内容源使用 `.mankai` 文件在不同设备上识别同一个内容源。如果 Mankai 无法写入该文件，内容源会使用本地标识，其记录不会同步。OPDS 使用目录的 ID，如果目录没有 ID，则改用本地标识。内置的**本地目录**始终将记录保留在本机。

文件夹名称相似并不代表内容源标识相同，内容源 ID 也必须一致。即使本地标识导致漫画记录无法同步，文件夹的连接设置仍可同步。要打开同步后的收藏，另一台设备必须能够访问对应的内容源和书籍。

## 内容源或阅读进度没有出现时

确认两台设备使用相同账户，并显示同步成功。在内容源的**同步**部分，分别检查设置同步和漫画同步的支持状态。请手动添加文件系统内容源及没有可用下载网址的插件，并确认另一台设备能够访问内容源。如果只有收藏或进度缺失，请检查内容源是否使用本地标识。在重置连接设置之前，先阅读[故障排查](/zh-cn/guides/troubleshooting/)。
