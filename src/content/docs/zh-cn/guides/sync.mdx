同步是可选功能，会传输受支持的收藏和阅读进度。书籍文件、已下载的章节和内容源配置需要在每台设备上分别准备。

你需要兼容的 HTTP 同步服务，或已经配置好的 Supabase 项目。请使用服务管理员提供的连接信息和账户。

## 选择同步服务

1. 打开**设置 → 同步**。
2. 选择**同步引擎**。如果不需要同步，请保留为**无**。
3. 按照下方对应的步骤完成设置。

### HTTP

1. 选择 **HTTP**，输入同步服务的服务器网址。
2. 轻点**保存配置**。
3. 在**凭据**中输入用户名和密码。
4. 轻点**登录**。

### Supabase

1. 选择 **Supabase**，输入管理员提供的项目网址和密钥。
2. 轻点**保存配置**。
3. 选择该服务配置的登录提供商，再轻点**登录**。
4. 完成登录流程并返回 Mankai。

### iCloud（即将推出）

iCloud 同步即将推出，目前尚不可用。现在请使用 HTTP 或 Supabase 在设备间同步。

## 同步两台设备

1. 状态显示为**已启用**后，轻点**立即同步**。
2. 确认上次同步时间已成功更新。
3. 在另一台设备上配置相同的服务和账户。
4. 在另一台设备上添加相同的书籍内容源，然后也轻点**立即同步**。
5. 打开受支持的书籍，并使用**继续**从上次的位置继续阅读。

## 保持内容源标识一致

文件夹内容源使用 `.mankai` 文件在不同设备上识别同一个内容源。如果 Mankai 无法写入该文件，内容源会使用本地标识，其记录不会同步。OPDS 使用目录的 ID，如果目录没有 ID，则改用本地标识。内置的**本地目录**始终将记录保留在本机。

文件夹名称相似并不代表内容源标识相同。要打开同步后的收藏，另一台设备必须能够访问对应的内容源。

## 阅读进度没有出现时

确认两台设备使用相同账户、都能打开同一内容源，并显示同步成功。检查内容源是否使用本地标识。在重置连接设置之前，先阅读[故障排查](/zh-cn/guides/troubleshooting/)。
