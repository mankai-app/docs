从**文件**、**书库**、**首页**或**设置 → 历史记录**打开书籍。详情页面包含书籍简介、章节列表和阅读按钮。

## 开始或继续阅读章节

1. 轻点**阅读**开始阅读，或轻点**继续**从上次的位置继续阅读。
2. 若要自行选择章节，请展开书籍的某个章节组并轻点章节。
3. 如果想反转章节顺序，请使用章节列表的排序按钮。

显示的章节组和信息取决于书籍及其内容源。已锁定或不可用的章节无法直接在阅读器中打开。

## 浏览书籍页面

1. 在**分页**模式中滑动翻页，或在**连续**模式中滚动浏览页面。
2. 轻点页面中央附近，可显示或隐藏控制按钮。
3. 拖动底部的页面滑块，跳转到另一页。
4. 使用滑块旁的上一章和下一章按钮，在可用章节之间切换。

滑动方向和轻点行为取决于阅读器偏好设置。如果章节加载失败，请检查连接，然后在阅读器中重试。

## 选择舒适的布局

轻点阅读器中的设置按钮，调整阅读布局和操作方式。

| 设置             | 用途                                     |
| ---------------- | ---------------------------------------- |
| **阅读器类型**   | 在**分页**与**连续**之间切换             |
| **反转阅读方向** | 在从左到右与从右到左阅读之间切换         |
| **轻点翻页**     | 通过轻点页面区域翻页                     |
| **图片布局**     | 选择**自动**、**每行一页**或**每行两页** |
| **智能分组**     | 根据页面内容的相似度自动分组             |

分页模式还提供水平或垂直导航，以及页面过渡选项。部分设置仅在适用于所选模式或书籍时显示。如果阅读器遵循书籍指定的阅读方向，方向控制可能会被停用。

要修改默认偏好，请打开**设置 → 阅读器**。你可以选择默认阅读器类型、决定是否遵循书籍的阅读方向，并分别调整各阅读模式的设置。在 iPad 上，想并排阅读双页时可以尝试**每行两页**。在 iPhone 上，**每行一页**可为每页提供更多空间。

## 接着上次的位置读

返回书籍详情并使用**继续**。也可以在**设置 → 历史记录**中找到最近读过的书籍。将作品加入收藏后，即使它不再位于历史记录顶部，也能在**首页**找到。

要为离线阅读做好准备，请阅读[收藏与下载](/zh-cn/guides/library/)。

要放大页面、减少内存占用或调整页面色调，请阅读[图片处理](/zh-cn/guides/image-processing/)。
