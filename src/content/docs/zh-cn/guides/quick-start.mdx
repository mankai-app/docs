选择来源，开始阅读并收藏喜欢的书籍。Mankai 支持推荐的流式来源，也能通过文件式来源打开自己的书籍。

如果尚未安装 Mankai，请先在[安装指南](/zh-cn/guides/installation/)中选择一种方式。

## 1. 认识主要页面

Mankai 有四个主要标签页。

| 标签页   | 主要内容                           |
| -------- | ---------------------------------- |
| **首页** | 已收藏的作品和已下载的书籍         |
| **书库** | 来源提供的作品列表和搜索功能       |
| **文件** | 本地书籍、已连接的共享和文件导入   |
| **设置** | 阅读偏好、来源、同步和阅读历史记录 |

## 2. 添加来源

选择以下两种方式之一：

- **流式（推荐）**：在**设置 → 来源**添加来源，搜索和阅读外部书库。请参考详细的[来源设置步骤](/zh-cn/guides/sources/#添加来源)。
- **文件式**：在**文件**中导入书籍文件，或连接本地与网络共享。请参考详细的[文件式来源设置](/zh-cn/guides/sources/#文件式来源)。

## 3. 查找书籍并阅读

### 找一本书

1. 打开**书库**查看来源提供的作品，或打开**文件**查看书籍文件和已连接的共享。
2. 从列表或文件夹中选择作品。如果来源支持搜索，也可以搜索想读的书籍。
3. 轻点书籍，打开包含简介、章节列表和阅读按钮的详情页面。

### 开始阅读

1. 轻点**阅读**开始阅读。若要选择指定章节，展开章节组后轻点所需章节。
2. 在**分页**模式中滑动翻页，或在**连续**模式中滚动浏览页面。
3. 轻点页面中央附近，可显示或隐藏阅读控制按钮。
4. 使用阅读器中的设置按钮，选择**分页**或**连续**阅读，并调整阅读布局。

## 4. 方便下次继续阅读

1. 返回书籍详情，轻点**收藏**。
2. 打开**首页**，在来源菜单中选择**收藏**。
3. 再次打开书籍，如果已有阅读进度，轻点**继续**。

收藏会将作品保留在收藏列表中。若来源支持更新检查，Mankai 也会自动检查已收藏作品是否有新章节。

:::note[收藏与离线阅读]

要离线阅读，请从支持下载的来源另外下载章节。

:::
