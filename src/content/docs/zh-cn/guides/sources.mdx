Mankai 有两种主要内容源：**文件式**内容源让你从不同文件系统和网络存储读取书籍文件。**流式**内容源通过内容插件连接外部书库。推荐使用流式内容源，直接浏览、搜索和阅读外部书库，并在插件支持时自动检查更新。

| 方式             | 适用内容                                                              | 使用位置                              |
| ---------------- | --------------------------------------------------------------------- | ------------------------------------- |
| **流式（推荐）** | 插件提供的外部书库，可依支持情况浏览、搜索、阅读并自动检查更新        | 在**设置 → 插件**添加，从**书库**使用 |
| **文件式**       | 本地文件系统、SMB、SFTP、NFS、WebDAV 或 OPDS 目录提供的受支持书籍文件 | **文件**                              |

OPDS 目录则通过**文件 → 添加文件**连接，详见下方的目录设置。

## 流式内容源（推荐）

流式内容源需要内容插件。插件让 Mankai 能从外部书库获取作品列表、搜索书籍、读取章节，并在支持时自动检查书籍或章节更新。请使用提供商给你的插件网址、JSON 定义或结构化书库。

### 添加内容插件

1. 打开**设置 → 插件**，轻点 **+** 按钮。
2. 在**添加插件**中选择提供商指定的类型：**本地**下的**文件系统**，或**远程**下的 **JavaScript** 或 **HTTP**。选择后会打开独立的配置页面。
3. 对于 **JavaScript**，输入提供的网址。如果获得的是 JSON 定义，请启用**使用 JSON**并粘贴内容。
4. 对于 **HTTP**，输入提供的插件网址。对于**文件系统**，选择提供商按规定结构组织的插件文件夹，并决定是否设为只读。
5. 轻点**添加**。返回**书库**，浏览插件支持的列表和搜索功能。

即使选择**文件系统**插件，内容也必须是符合 Mankai 结构的书库。这与存放普通书籍文件的文件夹不同。普通文件夹请使用**文件 → 添加文件**。搜索、自动检查更新、章节和下载功能是否可用，取决于插件的支持情况。

## 文件式内容源

文件式内容源适合直接打开 CBZ、CBR、EPUB、PDF 和 MMA 书籍文件。使用**文件**访问本地文件系统，或通过 SMB、SFTP、NFS、WebDAV 连接不同的网络共享和存储位置。也可以连接 OPDS 目录，打开受支持的书籍文件，或在目录支持时通过页面流式传输阅读。不支持通过 OPDS 读取 MMA 文件。普通书籍文件夹不需要内容插件。

**MMA（`.mma`）** 是 Mankai Manga Archive 的缩写，以 ZIP 归档打包书籍元数据、章节组和页面图片。有关归档结构和元数据，请参阅 [MMA 格式参考](/zh-cn/api/mma-format/)。

### 导入书籍文件

1. 打开**文件**，轻点**导入**按钮，图标是指向托盘的箭头。
2. 轻点**选择文件**，在“文件”中选择一本书。支持 CBZ、CBR、EPUB、PDF 和 MMA 格式。
3. 在**导入至**的**共享**中选择**本地目录**，将副本保存在 Mankai 内。如果已经添加支持导入的共享，也会显示其他目标位置。
4. 轻点**导入**。导入成功后，Mankai 会打开目标位置中的导入文件夹。

### 连接本地文件夹

1. 打开**文件 → 添加文件**。
2. 轻点**本地共享**下的**文件系统**，打开配置页面，也可以填写**显示名称**。
3. 轻点**选择文件夹**，在系统选择器中选择文件夹。
4. 轻点**添加**，然后在**文件**中打开新共享。
5. 打开子文件夹，或轻点支持的书籍文件查看详情。

连接文件夹后，Mankai 就能浏览该位置。如果想将选定文件复制到某个导入目标，请使用**导入**。

### 连接网络存储

1. 打开**文件 → 添加文件**，在**远程共享**下选择 **SMB**、**SFTP**、**NFS** 或 **WebDAV**。
2. 输入服务器管理员提供的连接信息。
3. 按照下表完成对应类型的操作。

| 内容源     | 需要填写的信息                     | 完成步骤                                                 |
| ---------- | ---------------------------------- | -------------------------------------------------------- |
| **SMB**    | 主机、端口，以及必要的用户名和密码 | 轻点**选择共享**，按提示选择共享位置，再轻点**添加**     |
| **SFTP**   | 主机、端口、用户名和密码           | 轻点**添加**                                             |
| **NFS**    | 主机                               | 轻点**选择导出目录**，按提示选择导出目录，再轻点**添加** |
| **WebDAV** | 服务器网址，以及必要的用户名和密码 | 轻点**添加**                                             |

如果 SMB 只找到一个共享位置，或 NFS 只找到一个导出目录，Mankai 会自动添加。然后从**文件**打开新内容源。浏览和阅读网络书籍时，请保持内容源可连接。

### 连接 OPDS 目录

OPDS 目录通过**文件**中的独立目录连接访问，不需要内容插件。目录可提供支持的书籍文件。若支持页面流式传输，也能直接流式阅读。

1. 打开**文件 → 添加文件**，轻点**目录**下的 **OPDS**。
2. 输入目录网址，以及必要的用户名和密码。
3. 轻点**添加**，然后从**文件**打开新目录。

浏览和阅读网络书籍时，请保持内容源可连接。

## 管理连接

在**文件**中滑动共享条目，可编辑或移除连接，也可以打开**设置 → 共享**查看。打开**设置 → 插件**可查看已安装的内容插件。

如果希望在不同设备间同步受支持的插件、共享连接、收藏和阅读进度，请阅读[跨设备同步](/zh-cn/guides/sync/)。如果连接遇到问题，请阅读[故障排查](/zh-cn/guides/troubleshooting/)。
