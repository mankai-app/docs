title: 故障排查
description: 解决导入、来源、阅读控制、下载和同步的常见问题。
---

从出现问题的页面开始。以下步骤有助于判断问题出在书籍、来源还是设置。

## 无法导入文件

1. 确认文件格式为 CBZ、CBR、EPUB、PDF 或 MMA。
2. 确认能在“文件”中访问该文件，并且已经从存储提供商下载完成。
3. 打开**文件 → 导入**，重新选择文件并检查**导入至**。
4. 尝试选择**本地目录**，判断问题是否来自原目标位置。
5. 如果出现错误，请保留错误信息，以便描述失败原因。

:::note[修改扩展名不会转换格式]

修改扩展名不会转换书籍格式。

:::

## 来源无法连接

检查网址或主机、所需的登录凭据和网络连接。设备必须能访问家庭网络中的服务器。对于本地文件夹，请确认该位置仍存在，而且能在“文件”中访问。

从**文件**打开来源再试一次。如果地址或账户发生变化，可滑动条目来编辑连接。[添加书籍与来源](/zh-cn/guides/sources/)列出了各类来源需要填写的字段。

## 书库或首页是空的

**书库**显示来源提供的列表。如果想阅读来源内容，请在**设置 → 来源**中添加并配置来源。只有可用来源支持搜索时，才会显示搜索功能。

**首页 → 收藏**包含已收藏的作品。打开书籍详情并轻点**收藏**，然后检查首页上的来源和状态筛选项。即使尚未收藏，也能在**文件**中找到已导入的书籍文件。

## 翻页方向不对

1. 轻点阅读页面中央，显示控制按钮。
2. 打开阅读器设置菜单，检查模式和阅读方向。
3. 如果轻点页面时出现意外翻页，请检查**轻点翻页**。
4. 打开**设置 → 阅读器**，查看默认设置，以及 Mankai 是否遵循书籍的阅读方向。

## 章节加载或下载失败

检查来源是否可访问。如果章节加载失败，请在阅读器中重试。如果下载失败，请轻点**首页**上的下载箭头，并轻点失败任务的重试按钮。等下载完成后再进行离线阅读。

:::note[收藏与离线阅读]

仅收藏作品并不能让章节离线可用。在首页的来源菜单中选择**下载**，即可查找已下载的内容。只有支持下载的来源才会显示下载操作。

:::

## 同步后无法恢复书籍

检查两台设备的账户和同步状态。同步会共享受支持的来源及其设置、共享连接、收藏和阅读进度。

:::note[书籍文件与下载]

书籍文件和已下载的章节仍需在另一台设备上准备。

:::

在**设置 → 来源**或**设置 → 共享**中打开来源，检查其**同步**状态。设置同步和漫画同步是独立的功能。请在每台设备上手动添加文件系统来源及没有可用下载网址的来源，并确认网络来源能够连接。

:::note[来源标识限制]

如果来源使用本地标识而不是稳定的来源标识，其收藏和阅读进度不会同步。关于来源标识的要求，请阅读[跨设备同步](/zh-cn/guides/sync/)。

:::

## 清楚描述问题

向来源提供商或应用维护者寻求帮助时，请提供设备、应用版本、来源类型、已尝试的步骤和准确的错误信息。如果附上截图，请隐藏密码、访问密钥和私人服务器信息。
