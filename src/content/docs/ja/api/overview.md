これらの API と形式仕様を使って、自分のコンテンツやサービスを Mankai に接続したり、MMA ブックアーカイブを作成したりできます。作成したいものに合ったリファレンスを選んでください。

Mankai は内部でプラグインを使ってソースと通信します。HTTP ソースには、Mankai の HTTP プラグインが呼び出せる互換サーバー API を実装します。JavaScript ソースには、JSON マニフェストとコールバックスクリプトを用意します。

アプリの設定と使い方は、[はじめて使う](/ja/guides/quick-start/)を参照してください。

## 連携方法を選ぶ

| 開発するもの                  | リファレンス                                         | 提供する機能                                                                                                           |
| :---------------------------- | :--------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------- |
| JavaScript のコンテンツソース | [JavaScript プラグイン](/ja/api/javascript-plugins/) | JSON マニフェストとコールバックで、閲覧、検索、漫画の詳細、チャプター、画像を提供します。                              |
| Mankai 互換漫画サーバー       | [Mankai 互換 API](/ja/api/http-api/)                 | Mankai の HTTP プラグインが呼び出す互換 HTTP エンドポイントで、閲覧、認証、検索、ライブラリの更新確認を提供します。    |
| Mankai 互換ソースの編集機能   | [エディター API](/ja/api/editor-api/)                | Mankai 互換 API に編集用のエンドポイントを追加し、漫画、チャプターグループ、チャプター、表紙、ページ画像を管理します。 |
| リモート画像処理サービス      | [画像処理 API](/ja/api/image-processors/)            | 設定可能な HTTP サービスでリーダーに表示する画像を処理します。任意で JWT 認証を使用できます。                          |
| 持ち運べるブックアーカイブ    | [MMA 形式](/ja/api/mma-format/)                      | 本のメタデータ、チャプターグループ、ページ画像を含む ZIP アーカイブです。                                              |

## 実装例

- [plugin](https://github.com/mankai-app/plugin) には、JavaScript ソースプラグインの実装例があります。
- [server](https://github.com/mankai-app/server) は、漫画の管理と同期に対応する互換 HTTP API を実装しています。
