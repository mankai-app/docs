**ホーム**にはコレクションとダウンロードがまとまっています。**ライブラリ**では、ソースが提供する作品を探せます。

## お気に入りを保存して探す

1. 本の詳細を開き、**ブックマーク**をタップします。
2. **ホーム**を開き、ソースのメニューで**コレクション**を選びます。
3. 保存した作品を検索したり、状態やソースで絞り込んだりできます。
4. コレクションの一覧を下に引くと、更新を確認できます。

ブックマークを外すには、本の詳細で**削除**をタップします。

:::note[ブックマークとダウンロード]

ブックマークの削除と、ダウンロードした本の削除は別の操作です。

:::

## 読みたい作品を探す

1. **ライブラリ**を開き、ソースが提供する一覧を表示します。
2. 一覧から作品を開きます。検索に対応するソースがある場合は、検索も使えます。
3. 本の詳細で**読む**、**続ける**、またはチャプターを選びます。

最近読んだ本に戻るには、**設定 → 履歴**を開きます。ブックマークしていない本も、読んだことがあれば履歴に表示されます。

## チャプターをダウンロードする

1. ダウンロードに対応するソースの本を開き、下向き矢印のダウンロードボタンをタップします。
2. **チャプターを選択**でグループを展開し、必要なチャプターを選びます。グループ横の丸い選択ボタンを使うと、そのグループで選択可能なチャプターをまとめて選べます。
3. **ダウンロード**をタップします。
4. **ホーム**のダウンロードボタンをタップすると、進行状況を確認できます。失敗したタスクには再試行ボタンが表示されます。

## オフラインで読んで容量を管理する

1. ソースに接続できる状態で、ダウンロードが完了するまで待ちます。
2. **ホーム**のソースメニューで**ダウンロード**を選び、本を開きます。
3. ダウンロード済みのチャプターを開いて、オフラインで読みます。

:::note[ダウンロード済みのチャプターのみ]

オフラインのコピーから読めるのは、ダウンロード済みのチャプターだけです。ブックマークしただけではページはダウンロードされません。

:::

容量を空けるには、ダウンロードのパネルで作品をスワイプし、**削除**を確定します。タスクの操作ボタンから、待機中の処理をキャンセルしたり、失敗した処理を再試行したりすることもできます。

## ダウンロード済みのチャプターをエクスポートする

ダウンロード済みのチャプターを選択し、**MMA** または **PDF** 形式でエクスポートできます。

- **MMA（Mankai Manga Archive）** は、選択したすべてのチャプターグループ、元のページ画像、本のメタデータ、表紙を 1 つの `.mma` ファイルにまとめます。通常は PDF より速くエクスポートできます。アーカイブの詳細は [MMA 形式](/ja/api/mma-format/)を参照してください。
- **PDF** は、選択したチャプターごとに個別の `.pdf` ファイルを作成します。3 つのチャプターを選択すると、3 つの PDF ファイルが作成されます。

1. エクスポートしたいチャプターをダウンロードし、完了するまで待ちます。
2. 本の詳細を開き、ツールバーまたは **•••** メニューから**エクスポート**を選びます。エクスポートボタンは、四角から上向き矢印が出ているアイコンです。
3. **エクスポート形式**で **MMA** または **PDF** を選びます。
4. チャプターグループを展開し、必要なチャプターを選びます。グループ横の丸い選択ボタンを使うと、そのグループのダウンロード済みチャプターをまとめて選べます。
5. **エクスポート**をタップし、**エクスポート完了**と表示されるまで待ちます。
6. **共有**をタップし、**ファイルに保存**などの保存先を選びます。エクスポート画面を閉じる前に、エクスポートしたファイルを保存または共有してください。

:::note[エクスポートできるチャプター]

エクスポートの一覧には、完全にダウンロードしたチャプターだけが表示されます。必要なチャプターがない場合は、ダウンロードを完了してからエクスポートしてください。

:::

**ホーム**のダウンロードパネルで本を長押しし、**エクスポート**を選ぶこともできます。
