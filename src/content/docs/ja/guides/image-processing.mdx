**設定 → 画像処理**を開くと、リーダーに表示するページの処理方法を選べます。各プロセッサの有効化、設定の調整、処理順序の変更ができます。

## ローカルプロセッサを選ぶ

ローカルプロセッサはデバイス上で動作します。初期状態では**4倍 Real-ESRGANアップスケーリング**が無効、**画像をダウンサンプリング**が有効です。

| プロセッサ                            | 用途                                                                                                           | 設定                                                                                                                                   |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **4倍 Real-ESRGANアップスケーリング** | realesr-animevideov3 モデルで低解像度のページを拡大します。画面表示に十分な大きさの画像は変更されません。      | **アップスケールの感度**で、拡大する画像の範囲を調整します。感度を上げると大きな画像も対象になり、処理能力とメモリの使用量が増えます。 |
| **画像をダウンサンプリング**          | 画像の解像度を下げてメモリ使用量を減らします。無効にすると元の解像度を維持できますが、メモリ使用量が増えます。 | **メモリ節約**は**低**、**バランス**、**高**から選べます。節約量を増やすと解像度が低くなります。                                       |
| **モノクロトーン**                    | 線の鮮明さとコントラストを保ちながら、ページを好みの色調にします。                                             | **トーンカラー**を選び、**トーンの強さ**を調整します。                                                                                 |

1. **設定 → 画像処理**を開き、**+**をタップします。
2. **ローカル**から追加したいプロセッサを選びます。追加したプロセッサは自動的に有効になります。
3. プロセッサの行をタップし、**設定**で各項目を調整します。変更は自動的に保存されます。
4. 行のスイッチで有効または無効にできます。無効にしても設定は残ります。

**アップスケールの感度**と**メモリ節約**は、まず**バランス**で試してください。拡大を使う場合は、その後に**画像をダウンサンプリング**を有効にすると、最終的な画像サイズとメモリ使用量を抑えられます。

## 処理順序を変更する

有効なプロセッサは上から順に実行されます。各プロセッサは直前の処理結果を受け取るため、順序を変えると結果が変わることがあります。

1. **画像処理**で**編集**をタップします。
2. 並べ替えハンドルをドラッグして順序を変更します。
3. **完了**をタップします。

拡大した後にメモリを節約する場合は、**4倍 Real-ESRGANアップスケーリング**を**画像をダウンサンプリング**より上に置きます。最終的なページの色を調整したい場合は、その後に**モノクロトーン**を追加します。

## リモート画像プロセッサを追加する

リモートプロセッサはリーダーの画像をサーバーに送り、返された画像をリーダーに表示します。Mankai に対応した画像処理サービスと、iPhone または iPad から接続できるサーバー URL が必要です。

1. **設定 → 画像処理**を開き、**+**をタップします。
2. **リモート**から**リモート画像プロセッサ**を選びます。
3. **サーバURL**にサービスのベース URL を入力し、**追加**をタップします。Mankai がサーバーの名前と設定項目を読み込みます。
4. 追加したプロセッサの行をタップし、**設定**を調整します。認証が必要な場合は、提供された**ユーザー名**と**パスワード**を入力します。
5. スイッチが有効になっていることを確認し、処理順序を調整します。

:::note[リモートサーバーへの接続]

`https://images.example.com/mankai` のようなベース URL を入力してください。`/process` エンドポイントの URL は使いません。自宅のネットワーク上のサーバーを使う場合は、読書中もデバイスから接続できる必要があります。処理サーバーへの接続なしで実行できるのはローカルプロセッサです。

:::

リモートプロセッサには、その処理位置にある画像が送られます。たとえば**モノクロトーン**の後に置くと、色調を変更した画像が送信されます。利用できる設定と効果はサービスによって異なります。

対応するサーバーを開発する場合は、[画像処理 API](/ja/api/image-processors/)を参照してください。

## 設定をリセットする、プロセッサを削除する

プロセッサの行をタップし、**設定をリセット**、**リセット**の順にタップすると、初期設定に戻せます。

:::caution[リモート認証情報のリセット]

認証が必要なリモートプロセッサでは、ユーザー名とパスワードも消去されます。

:::

削除するには行をスワイプして**削除**を確認するか、設定画面の**削除**を使います。設定を残して効果を一時停止したい場合は、スイッチをオフにします。

## 処理が遅い、効果が見えない場合

- プロセッサが有効か、一覧での位置が適切かを確認します。
- 拡大処理は、画面表示に十分な大きさの画像を対象にしません。**アップスケールの感度**を上げる前に、低解像度のページで試してください。
- 拡大処理が遅い場合は**アップスケールの感度**を下げるか、プロセッサを無効にします。メモリ使用量を減らすには、**画像をダウンサンプリング**を有効にしておきます。
- リモートプロセッサでは、ベース URL、サーバーの稼働状況、接続、認証情報を確認します。

:::note[元の画像で読書を続ける]

拡大処理やリモート処理の完了を待つ間は、元のページが表示されることがあります。処理に失敗しても、元の画像で読書を続けられます。

:::

ページ配置や操作方法は、[読書とリーダー設定](/ja/guides/reading/)を参照してください。
