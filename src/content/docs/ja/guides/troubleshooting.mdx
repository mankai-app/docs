以下から該当する問題を探してください。手順に沿って、本、ソース、設定のどこに原因があるかを確認できます。

## ファイルをインポートできない

1. ファイルが CBZ、CBR、EPUB、PDF のいずれかであることを確認します。拡張子を変えるだけでは形式は変換されません。
2. ファイルアプリからアクセスでき、ファイルの保存先からのダウンロードが完了していることを確認します。
3. **ブラウズ → インポート**を開き、ファイルを選び直して**インポート先**を確認します。
4. **ローカルディレクトリ**を選んで試すと、元の保存先に原因があるかを確認できます。
5. エラーが表示された場合は、問題を説明できるようにメッセージを控えておきます。

## ソースに接続できない

URL やホスト、必要な認証情報、ネットワーク接続を確認します。自宅のネットワーク内にあるサーバーを使う場合は、デバイスから接続できる状態にしてください。ローカルフォルダの場合は、その場所が存在し、ファイルアプリから利用できることを確認してください。

**ブラウズ**からソースを開いて再試行します。アドレスやアカウントが変わった場合は、行をスワイプして接続を編集できます。種類ごとの入力欄は、[本とソースを追加する](/ja/guides/sources/)をご覧ください。

## ライブラリやホームに本が表示されない

**ライブラリ**にはプラグインが提供する一覧が表示されます。プラグインが提供する作品を読みたい場合は、**設定 → プラグイン**で追加と設定を行います。検索は、利用可能なプラグインが検索に対応している場合に表示されます。

**ホーム → コレクション**にはブックマークが表示されます。本の詳細で**ブックマーク**をタップし、ホームのソースや状態の絞り込みを確認してください。インポートした本のファイルは、ブックマークしていなくても**ブラウズ**から開けます。

## ページが意図しない方向に進む

1. 読書中のページの中央をタップして、操作ボタンを表示します。
2. リーダーの設定メニューを開き、種類と閲覧方向を確認します。
3. タップすると意図せずページが進む場合は、**タップナビゲーション**を確認します。
4. **設定 → リーダー**で標準の設定と、本の閲覧方向を優先するかを確認します。

## チャプターの読み込みやダウンロードに失敗する

ソースに接続できるか確認します。読み込みに失敗した場合は、チャプターの読み込みを再試行します。ダウンロードに失敗した場合は、**ホーム**のダウンロードボタンをタップし、該当タスクの再試行ボタンをタップします。オフラインで読む前に、ダウンロードの完了を確認してください。

ブックマークしただけでは、オフラインで読めるようにはなりません。**ホーム**のソースメニューで**ダウンロード**を選ぶと、ダウンロードした作品が見つかります。ダウンロードの操作は、対応するソースでのみ表示されます。

## 同期しても本を開けない

両方のデバイスでアカウント、同期状況、ソースの ID を確認します。同期されるのは、対応するブックマークと読書記録です。もう一方のデバイスでも、同じソースと本にアクセスできる必要があります。デバイス専用の ID に関する制限は、[デバイス間で同期する](/ja/guides/sync/)を参照してください。

## 問題を具体的に伝える

ソースの提供元やアプリの開発者に問い合わせる際は、デバイス、アプリのバージョン、ソースの種類、試した手順、正確なエラーメッセージを伝えてください。スクリーンショットを添付する場合は、パスワード、アクセスキー、非公開のサーバー情報を隠してください。
