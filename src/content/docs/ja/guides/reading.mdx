**ファイル**、**ライブラリ**、**ホーム**、または**設定 → 履歴**から本を開きます。詳細画面には、本の説明、チャプター一覧、読書を開始するボタンがまとまっています。

## チャプターを読む、続きから再開する

1. **読む**をタップして読み始めます。読書記録がある場合は、**続ける**で再開できます。
2. チャプターを自分で選ぶ場合は、チャプターグループを開いて読みたいものをタップします。
3. 一覧を逆順にしたい場合は、チャプター一覧の並べ替えボタンを使います。

表示されるグループや情報は、本とソースによって異なります。ロックされているチャプターや利用できないチャプターは、通常のリーダー操作では開けません。

## ページやチャプターを移動する

1. **ページ送り**ではスワイプしてページをめくり、**連続**ではスクロールして読み進めます。
2. ページの中央付近をタップすると、操作ボタンを表示または非表示にできます。
3. 画面下部のページスライダーをドラッグすると、別のページに移動できます。
4. スライダーの左右にある前後のチャプターボタンで、利用可能なチャプターに移動できます。

スワイプの方向やタップ時の動作は、リーダー設定によって変わります。チャプターの読み込みに失敗した場合は、接続を確認してからリーダーで再試行してください。

## 読みやすい配置を選ぶ

リーダー内の設定ボタンをタップすると、読書画面の表示を調整できます。

| 設定                     | できること                                         |
| ------------------------ | -------------------------------------------------- |
| **リーダーの種類**       | **ページ送り**と**連続**の切り替え                 |
| **閲覧方向を反転**       | 左から右と右から左への読み方を切り替える           |
| **タップナビゲーション** | ページの領域をタップして移動する                   |
| **画像のレイアウト**     | **自動**、**1行に1ページ**、**1行に2ページ**を選ぶ |
| **スマートグループ化**   | 内容の類似性に基づいてページを自動的に組み合わせる |

ページ送りモードでは、水平方向と垂直方向の移動や、ページの切り替え方法も選べます。モードや本に応じて、適用できる設定だけが表示される場合があります。本に指定された閲覧方向を優先している場合は、方向を変える操作が無効になることがあります。

標準の設定を変更するには、**設定 → リーダー**を開きます。標準のリーダーの種類、本に指定された閲覧方向を優先するか、各モードの動作を調整できます。iPad で見開きにしたい場合は**1行に2ページ**を試してください。iPhone では**1行に1ページ**にすると、各ページを広く表示できます。

## 続きから読む

本の詳細に戻って**続ける**を使います。**設定 → 履歴**から最近読んだ本を見つけることもできます。ブックマークしておけば、履歴の上位に表示されなくなっても**ホーム**から探せます。

オフラインで読む準備は、[コレクションとダウンロード](/ja/guides/library/)を参照してください。

ページの拡大、メモリ使用量の削減、色調の調整は、[画像処理](/ja/guides/image-processing/)を参照してください。
