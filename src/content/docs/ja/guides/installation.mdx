iPhone または iPad に Mankai をインストールする方法を選びます。

| 方法                   | 費用 | 提供状況 |
| ---------------------- | ---- | -------- |
| App Store              | 有料 | 近日公開 |
| サイドロード           | 無料 | 近日公開 |
| ソースコードからビルド | 無料 | 利用可能 |

## App Store

**有料・近日公開。** Mankai は App Store で有料アプリとして公開予定です。App Store 版はまだ利用できません。

## サイドロード

**無料・近日公開。** IPA ビルドを使ったサイドロードは近日公開予定です。IPA はまだダウンロードできません。現在は、以下の手順でソースコードからビルドしてください。

## ソースコードからビルド

**無料。** Mac の Xcode で Mankai を自分でビルドします。

1. [Mankai のリポジトリ](https://github.com/mankai-app/mankai)をクローンするか、ソースコードをダウンロードします。
2. Xcode で `mankai.xcodeproj` を開き、Swift パッケージの依存関係が解決されるまで待ちます。
3. **Signing & Capabilities** で、アプリとサムネイル拡張機能のターゲットに自分の開発チームを設定します。必要に応じて、ビルド用に一意のバンドル ID を設定します。
4. **mankai** スキームと接続した iPhone または iPad を選び、**Run** でビルドしてインストールします。

インストールできたら、[はじめて使う](/ja/guides/quick-start/)で最初の本をインポートしてください。
