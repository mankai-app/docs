ソースには、**ストリーム型**と**ファイル型**の 2 つの方法があります。外部ライブラリの作品を探して読み、更新を確認するには、コンテンツ用プラグインを使うストリーム型ソースをおすすめします。

| 方法                         | 用途                                                                                                   | 開く場所       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ | -------------- |
| **ストリーム型（おすすめ）** | コンテンツ用プラグインを通じて外部ライブラリを閲覧、検索、読書。対応するプラグインでは更新を自動で確認 | **ライブラリ** |
| **ファイル型**               | ローカルやネットワークストレージにある CBZ、CBR、EPUB、PDF の本を開く                                  | **ブラウズ**   |

## ストリーム型ソースを追加する（おすすめ）

ストリーム型ソースには、外部ライブラリに接続するコンテンツ用プラグインが必要です。プラグインを使うと、外部ライブラリの作品を探し、検索し、読むことができます。プラグインが対応している場合は、新しいチャプターなどの更新を自動で確認できるため、この方法をおすすめします。

### コンテンツ用プラグインを追加する

1. **設定 → プラグイン**を開き、**+** ボタンをタップします。
2. 提供元が指定したプラグインの種類を選びます。
3. **JavaScript** の場合は、案内された URL を入力します。JSON 定義を受け取った場合は、**JSONを使用**を有効にして貼り付けます。
4. **HTTP** の場合は、案内されたプラグインの URL を入力します。**ファイルシステム**の場合は、提供元が用意したプラグイン用フォルダを選び、読み取り専用にするかを設定します。
5. **追加**をタップします。**ライブラリ**に戻ると、そのプラグインが提供する作品一覧や検索を使えます。

ファイルシステムプラグインには、Mankai が定めるフォルダ構成に従ったライブラリが必要です。通常の本ファイルを保存したフォルダには、**ブラウズ → フォルダを追加**を使います。検索、チャプター、ダウンロード、自動更新確認の各機能は、プラグインの対応状況によって異なります。

## ファイル型ソースを追加する

ファイル型ソースでは、ローカルのファイルシステムや SMB、SFTP、NFS、WebDAV のネットワークストレージにある本を、**ブラウズ**から開きます。CBZ、CBR、EPUB、PDF 形式に対応しています。

### 本のファイルをインポートする

1. **ブラウズ**を開き、トレイに向かう矢印が描かれた**インポート**ボタンをタップします。
2. **ファイルを選択**をタップし、ファイルアプリで本を選びます。CBZ、CBR、EPUB、PDF 形式に対応しています。
3. **インポート先**で**ローカルディレクトリ**を選ぶと、Mankai 内にコピーを保存できます。インポートに対応するソースを追加済みの場合は、ほかの保存先も選べます。
4. **インポート**をタップします。成功すると、保存先のインポート用フォルダが開きます。

### ローカルフォルダに接続する

1. **ブラウズ → フォルダを追加**を開きます。
2. **フォルダの種類**を**ファイルシステム**にします。必要に応じて表示名も入力します。
3. **フォルダを選択**をタップし、システムの選択画面でフォルダを選びます。
4. **追加**をタップし、**ブラウズ**から追加したフォルダを開きます。
5. サブフォルダを開くか、対応する本をタップして詳細を表示します。

フォルダを接続すると、その場所の内容を参照できます。選択したファイルを保存先にコピーしたい場合は、**インポート**を使います。

### ネットワークストレージに接続する

1. **ブラウズ → フォルダを追加**を開き、該当する**フォルダの種類**を選びます。
2. サーバー管理者から案内された接続情報を入力します。
3. 種類に応じて、次の操作で追加を完了します。

| ソース     | 入力する情報                                       | 最後の操作                                                                           |
| ---------- | -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **SMB**    | ホスト、ポート、必要な場合はユーザー名とパスワード | **共有を選択**をタップし、選択画面が表示されたら共有を選んで**追加**                 |
| **SFTP**   | ホスト、ポート、ユーザー名、パスワード             | **追加**をタップ                                                                     |
| **NFS**    | ホスト                                             | **エクスポートを選択**をタップし、選択画面が表示されたらエクスポートを選んで**追加** |
| **WebDAV** | サーバー URL、必要な場合はユーザー名とパスワード   | **追加**をタップ                                                                     |

SMB の共有や NFS のエクスポートが 1 つだけ見つかった場合は、自動的に追加されます。追加後は**ブラウズ**から開けます。ネットワーク上の本を閲覧・読書する間は、ソースに接続できる状態を保ってください。

## OPDS カタログに接続する

OPDS カタログも**ブラウズ**から追加できます。カタログから対応する本ファイルを開いたり、カタログが対応している場合はページをストリーミングして読んだりできます。コンテンツ用プラグインの追加とは別の手順です。

1. **ブラウズ → フォルダを追加**を開き、**フォルダの種類**を**OPDS**にします。
2. カタログ URL と、必要な場合はユーザー名とパスワードを入力します。
3. **追加**をタップし、**ブラウズ**からカタログを開きます。

## 接続を管理する

**ブラウズ**でフォルダの行をスワイプすると、接続の編集や削除ができます。**設定 → フォルダ**から詳細を確認することもできます。コンテンツ用プラグインの詳細は、**設定 → プラグイン**から開きます。

デバイス間で読書記録を共有する場合は、[デバイス間で同期する](/ja/guides/sync/)をご覧ください。接続できない場合は、[問題が起きたとき](/ja/guides/troubleshooting/)をご確認ください。
