ソースには、**ストリーム型**と**ファイル型**の 2 つの方法があります。外部ライブラリの作品を探して読み、更新を確認するには、ストリーム型ソースをおすすめします。

| 方法                         | 用途                                                                               | 開く場所       |
| ---------------------------- | ---------------------------------------------------------------------------------- | -------------- |
| **ストリーム型（おすすめ）** | ソースを通じて外部ライブラリを閲覧、検索、読書。対応するソースでは更新を自動で確認 | **ライブラリ** |
| **ファイル型**               | ローカルフォルダ、ネットワークストレージ、OPDS カタログの対応する本を開く          | **ファイル**   |

## ストリーム型ソースを追加する（おすすめ）

ストリーム型ソースを追加すると、外部ライブラリの作品を探し、検索し、読むことができます。ソースが対応している場合は、新しいチャプターなどの更新を自動で確認できるため、この方法をおすすめします。

### ソースを追加する

1. **設定 → ソース**を開き、**+** ボタンをタップします。
2. **ソースを追加**で、提供元が指定した種類を選び、専用の設定画面を開きます。
3. 下の表を参考に、ソースの種類に応じた情報を入力します。
4. **追加**をタップします。**ライブラリ**に戻ると、そのソースが提供する作品一覧や検索を使えます。

| ソース               | 設定内容                                                                                                                                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ファイルシステム** | **フォルダを選択**から提供元が用意したライブラリ用フォルダを選びます。編集を防ぎたい場合は**読み取り専用**を有効にします。                                                                                   |
| **JavaScript**       | 案内された URL を入力するか、**JSONを使用**を有効にして JSON 定義を貼り付けます。                                                                                                                            |
| **Mankai 互換**      | サーバーの API URL と、必要なユーザー名とパスワードを入力します。                                                                                                                                            |
| **Komgaサーバー**    | サーバーの URL と、APIキーまたは Komga のユーザー名とパスワードを入力します。                                                                                                                                |
| **Kavitaサーバー**   | サーバーの URL と Kavita のユーザー名とパスワードを入力するか、Kavita の**ユーザー設定 → サードパーティクライアント**で作成した認証キーを **APIキー**欄に入力します。                                        |
| **Suwayomiサーバー** | サーバーの URL を入力し、**認証モード**をサーバーの設定に合わせて**なし**、**Basic認証**、**シンプルログイン**、**UIログイン**から選びます。**なし**以外を選んだ場合は、ユーザー名とパスワードも入力します。 |

検索、チャプター、ダウンロード、自動更新確認の各機能は、ソースの対応状況によって異なります。

:::note[ソースごとの注意点]

- **ファイルシステム:** Mankai が定めるフォルダ構成に従ったライブラリが必要です。通常の本ファイルを保存したフォルダには、**ファイル → ファイルを追加**を使います。
- **Kavita:** 画像、アーカイブ、PDF 形式のシリーズが表示されます。EPUB 形式のシリーズは表示されません。
- **Suwayomi:** Suwayomi サーバーのライブラリに追加済みの作品が表示されます。

:::

## ファイル型ソースを追加する

ファイル型ソースでは、ローカルのファイルシステムや SMB、SFTP、NFS、WebDAV のネットワークストレージにある本を、**ファイル**から開きます。CBZ、CBR、EPUB、PDF、MMA 形式に対応しています。OPDS カタログに接続して、対応する本ファイルを開いたり、カタログが対応している場合はページをストリーミングして読んだりすることもできます。

:::note[OPDS の対応形式]

OPDS 経由での MMA ファイルの読み込みには対応していません。

:::

**MMA（`.mma`）** は Mankai Manga Archive の略です。本のメタデータ、チャプターグループ、ページ画像を ZIP アーカイブにまとめた形式です。アーカイブの構造とメタデータについては、[MMA 形式リファレンス](/ja/api/mma-format/)を参照してください。

### 本のファイルをインポートする

1. **ファイル**を開き、トレイに向かう矢印が描かれた**インポート**ボタンをタップします。
2. **ファイルを選択**をタップし、ファイルアプリで本を選びます。CBZ、CBR、EPUB、PDF、MMA 形式に対応しています。
3. **インポート先**の**共有**で**ローカルディレクトリ**を選ぶと、Mankai 内にコピーを保存できます。インポートに対応する共有を追加済みの場合は、ほかの保存先も選べます。
4. **インポート**をタップします。成功すると、保存先のインポート用フォルダが開きます。

### ローカルフォルダに接続する

1. **ファイル → ファイルを追加**を開きます。
2. **ローカル共有**の**ファイルシステム**をタップして設定画面を開きます。必要に応じて**表示名**も入力します。
3. **フォルダを選択**をタップし、システムの選択画面で共有を選びます。
4. **追加**をタップし、**ファイル**から追加した共有を開きます。
5. サブフォルダを開くか、対応する本をタップして詳細を表示します。

フォルダを接続すると、その場所の内容を参照できます。選択したファイルを保存先にコピーしたい場合は、**インポート**を使います。

### ネットワークストレージに接続する

1. **ファイル → ファイルを追加**を開き、**リモート共有**から **SMB**、**SFTP**、**NFS**、**WebDAV** のいずれかを選びます。
2. サーバー管理者から案内された接続情報を入力します。
3. 種類に応じて、次の操作で追加を完了します。

| ソース     | 入力する情報                                       | 最後の操作                                                                           |
| ---------- | -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **SMB**    | ホスト、ポート、必要な場合はユーザー名とパスワード | **共有を選択**をタップし、選択画面が表示されたら共有を選んで**追加**                 |
| **SFTP**   | ホスト、ポート、ユーザー名、パスワード             | **追加**をタップ                                                                     |
| **NFS**    | ホスト                                             | **エクスポートを選択**をタップし、選択画面が表示されたらエクスポートを選んで**追加** |
| **WebDAV** | サーバー URL、必要な場合はユーザー名とパスワード   | **追加**をタップ                                                                     |

:::note[共有の自動選択]

SMB の共有や NFS のエクスポートが 1 つだけ見つかった場合は、自動的に追加されます。

:::

追加後は**ファイル**から開けます。ネットワーク上の本を閲覧・読書する間は、ソースに接続できる状態を保ってください。

### OPDS カタログに接続する

OPDS カタログも**ファイル**から追加できます。カタログから対応する本ファイルを開いたり、カタログが対応している場合はページをストリーミングして読んだりできます。ソースの追加とは別の手順です。

1. **ファイル → ファイルを追加**を開き、**カタログ**の **OPDS** をタップします。
2. カタログ URL と、必要な場合はユーザー名とパスワードを入力します。
3. **追加**をタップし、**ファイル**からカタログを開きます。

## 接続を管理する

**ファイル**で共有の行をスワイプすると、接続の編集や削除ができます。**設定 → 共有**から詳細を確認することもできます。ソースの詳細は、**設定 → ソース**から開きます。

対応するソース、共有の接続設定、ブックマーク、読書記録をデバイス間で共有する場合は、[デバイス間で同期する](/ja/guides/sync/)をご覧ください。接続できない場合は、[問題が起きたとき](/ja/guides/troubleshooting/)をご確認ください。
