ソースには、**ストリーム型**と**ファイル型**の 2 つの方法があります。外部ライブラリの作品を探して読み、更新を確認するには、コンテンツ用プラグインを使うストリーム型ソースをおすすめします。

| 方法                         | 用途                                                                                                   | 開く場所       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ | -------------- |
| **ストリーム型（おすすめ）** | コンテンツ用プラグインを通じて外部ライブラリを閲覧、検索、読書。対応するプラグインでは更新を自動で確認 | **ライブラリ** |
| **ファイル型**               | ローカルフォルダ、ネットワークストレージ、OPDS カタログの対応する本を開く                              | **ファイル**   |

## ストリーム型ソースを追加する（おすすめ）

ストリーム型ソースには、外部ライブラリに接続するコンテンツ用プラグインが必要です。プラグインを使うと、外部ライブラリの作品を探し、検索し、読むことができます。プラグインが対応している場合は、新しいチャプターなどの更新を自動で確認できるため、この方法をおすすめします。

### コンテンツ用プラグインを追加する

1. **設定 → プラグイン**を開き、**+** ボタンをタップします。
2. **プラグインを追加**で、提供元が指定した種類を選びます。**ローカル**には**ファイルシステム**、**リモート**には **JavaScript** と **HTTP** があり、選ぶと専用の設定画面が開きます。
3. **JavaScript** の場合は、案内された URL を入力します。JSON 定義を受け取った場合は、**JSONを使用**を有効にして貼り付けます。
4. **HTTP** の場合は、案内されたプラグインの URL を入力します。**ファイルシステム**の場合は、**フォルダを選択**から提供元が用意したプラグイン用フォルダを選び、編集を防ぎたい場合は**読み取り専用**を有効にします。
5. **追加**をタップします。**ライブラリ**に戻ると、そのプラグインが提供する作品一覧や検索を使えます。

ファイルシステムプラグインには、Mankai が定めるフォルダ構成に従ったライブラリが必要です。通常の本ファイルを保存したフォルダには、**ファイル → ファイルを追加**を使います。検索、チャプター、ダウンロード、自動更新確認の各機能は、プラグインの対応状況によって異なります。

## ファイル型ソースを追加する

ファイル型ソースでは、ローカルのファイルシステムや SMB、SFTP、NFS、WebDAV のネットワークストレージにある本を、**ファイル**から開きます。CBZ、CBR、EPUB、PDF、MMA 形式に対応しています。OPDS カタログに接続して、対応する本ファイルを開いたり、カタログが対応している場合はページをストリーミングして読んだりすることもできます。OPDS 経由での MMA ファイルの読み込みには対応していません。

**MMA（`.mma`）** は Mankai Manga Archive の略です。本のメタデータ、チャプターグループ、ページ画像を ZIP アーカイブにまとめた形式です。アーカイブの構造とメタデータについては、[MMA 形式リファレンス](/ja/api/mma-format/)を参照してください。

### 本のファイルをインポートする

1. **ファイル**を開き、トレイに向かう矢印が描かれた**インポート**ボタンをタップします。
2. **ファイルを選択**をタップし、ファイルアプリで本を選びます。CBZ、CBR、EPUB、PDF、MMA 形式に対応しています。
3. **インポート先**の**共有**で**ローカルディレクトリ**を選ぶと、Mankai 内にコピーを保存できます。インポートに対応する共有を追加済みの場合は、ほかの保存先も選べます。
4. **インポート**をタップします。成功すると、保存先のインポート用フォルダが開きます。

### ローカルフォルダに接続する

1. **ファイル → ファイルを追加**を開きます。
2. **ローカル共有**の**ファイルシステム**をタップして設定画面を開きます。必要に応じて**表示名**も入力します。
3. **フォルダを選択**をタップし、システムの選択画面で共有を選びます。
4. **追加**をタップし、**ファイル**から追加した共有を開きます。
5. サブフォルダを開くか、対応する本をタップして詳細を表示します。

フォルダを接続すると、その場所の内容を参照できます。選択したファイルを保存先にコピーしたい場合は、**インポート**を使います。

### ネットワークストレージに接続する

1. **ファイル → ファイルを追加**を開き、**リモート共有**から **SMB**、**SFTP**、**NFS**、**WebDAV** のいずれかを選びます。
2. サーバー管理者から案内された接続情報を入力します。
3. 種類に応じて、次の操作で追加を完了します。

| ソース     | 入力する情報                                       | 最後の操作                                                                           |
| ---------- | -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **SMB**    | ホスト、ポート、必要な場合はユーザー名とパスワード | **共有を選択**をタップし、選択画面が表示されたら共有を選んで**追加**                 |
| **SFTP**   | ホスト、ポート、ユーザー名、パスワード             | **追加**をタップ                                                                     |
| **NFS**    | ホスト                                             | **エクスポートを選択**をタップし、選択画面が表示されたらエクスポートを選んで**追加** |
| **WebDAV** | サーバー URL、必要な場合はユーザー名とパスワード   | **追加**をタップ                                                                     |

SMB の共有や NFS のエクスポートが 1 つだけ見つかった場合は、自動的に追加されます。追加後は**ファイル**から開けます。ネットワーク上の本を閲覧・読書する間は、ソースに接続できる状態を保ってください。

### OPDS カタログに接続する

OPDS カタログも**ファイル**から追加できます。カタログから対応する本ファイルを開いたり、カタログが対応している場合はページをストリーミングして読んだりできます。コンテンツ用プラグインの追加とは別の手順です。

1. **ファイル → ファイルを追加**を開き、**カタログ**の **OPDS** をタップします。
2. カタログ URL と、必要な場合はユーザー名とパスワードを入力します。
3. **追加**をタップし、**ファイル**からカタログを開きます。

## 接続を管理する

**ファイル**で共有の行をスワイプすると、接続の編集や削除ができます。**設定 → 共有**から詳細を確認することもできます。コンテンツ用プラグインの詳細は、**設定 → プラグイン**から開きます。

対応するプラグイン、共有の接続設定、ブックマーク、読書記録をデバイス間で共有する場合は、[デバイス間で同期する](/ja/guides/sync/)をご覧ください。接続できない場合は、[問題が起きたとき](/ja/guides/troubleshooting/)をご確認ください。
