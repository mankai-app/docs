同期は任意の機能です。対応するブックマークと読書記録を共有できます。本のファイル、ダウンロードしたチャプター、ソースの設定は、各デバイスで別途用意する必要があります。

互換性のある HTTP 同期サービス、または設定済みの Supabase プロジェクトが必要です。利用するサービスの接続情報を使ってください。

## 同期サービスを選ぶ

1. **設定 → 同期**を開きます。
2. **同期エンジン**を選びます。同期が不要な場合は**なし**のままで構いません。
3. 選んだサービスに応じて、以下の手順で設定します。

### HTTP

HTTP 同期を使う前に、以下のいずれかのリポジトリを使って、互換性のあるサーバーを用意してください。

- [Mankai Sync](https://github.com/mankai-app/sync)：ユーザー管理用の管理画面を備えた同期専用サーバー。
- [Mankai Server](https://github.com/mankai-app/server)：ブックマークと読書記録の同期にも対応する漫画ライブラリサーバー。

選んだリポジトリのセットアップ手順に従ってください。サーバーの API URL（これらのサーバーでは `/api` で終わる URL）と、そのサーバー上のアカウントの認証情報を使います。既存のサービスを使う場合は、管理者からこれらの情報を入手してください。

1. **HTTP** を選び、**サーバURL**にサービスの API URL を入力します。
2. **設定を保存**をタップします。
3. **認証情報**にユーザー名とパスワードを入力します。
4. **ログイン**をタップします。

### Supabase

Supabase 同期を使う前に、Supabase プロジェクトを作成し、[Mankai Supabase リポジトリ](https://github.com/mankai-app/supabase)のセットアップ手順に従って、データベースのマイグレーション、Edge Functions のデプロイ、OAuth 認証プロバイダーの設定を完了してください。設定済みの既存プロジェクトを使う場合は、管理者からプロジェクト URL とキーを入手してください。

1. **Supabase** を選び、設定済みプロジェクトの URL とキーを入力します。
2. **設定を保存**をタップします。
3. プロジェクトで設定されている認証プロバイダーを選び、**ログイン**をタップします。
4. ログインを完了し、Mankai に戻ります。

### iCloud（近日公開）

iCloud 同期は近日公開予定で、まだ利用できません。現在、デバイス間で同期するには HTTP または Supabase を選んでください。

## 両方のデバイスを同期する

1. 状態が**有効**になったら、**今すぐ同期**をタップします。
2. 最終同期日時が更新されたことを確認します。
3. もう一方のデバイスでも、同じサービスとアカウントを設定します。
4. 同じ本のソースを追加し、そのデバイスでも**今すぐ同期**をタップします。
5. 対応する本を開き、**続ける**で前回の続きから再開します。

## ソースを同じものとして識別できるようにする

フォルダのソースは `.mankai` ファイルを使い、デバイス間で同じソースを識別します。Mankai がそのファイルを書き込めない場合はデバイス専用の ID が使われ、そのソースの記録は同期されません。OPDS はカタログの ID を使いますが、カタログに ID がない場合はデバイス専用の ID になります。組み込みの**ローカルディレクトリ**の記録は、そのデバイス内に保存されます。

フォルダの表示名が似ていても、ソースの ID が異なれば同じソースにはなりません。また、同期されたブックマークの本を開くには、そのデバイスからソースを利用できる必要があります。

## 読書の進み具合が表示されない場合

両方のデバイスで同じアカウントを使い、同じソースを開けること、同期が成功していることを確認します。ソースがデバイス専用の ID を使っていないかも確認してください。接続設定をリセットする前に、[問題が起きたとき](/ja/guides/troubleshooting/)をご覧ください。
