同期は任意の機能です。対応するソースとその設定、共有の接続設定、ブックマーク、読書記録をデバイス間で共有できます。

:::note[本のファイルとダウンロード]

本のファイルとダウンロードしたチャプターは、各デバイスで別途用意する必要があります。

:::

互換性のあるカスタムサーバー、または設定済みの Supabase プロジェクトが必要です。利用するサービスの接続情報を使ってください。

## 同期サービスを選ぶ

1. **設定 → 同期**を開きます。
2. **同期エンジン**で**カスタムサーバー**または **Supabase** を選びます。同期が不要な場合は**なし**のままで構いません。
3. 選んだサービスに応じて、以下の手順で設定します。

### iCloud（近日公開）

:::note[iCloud の利用可否]

iCloud 同期は近日公開予定で、まだ利用できません。現在、デバイス間で同期するにはカスタムサーバーまたは Supabase を選んでください。

:::

### カスタムサーバー

カスタムサーバーで同期する前に、以下のいずれかのリポジトリを使って、互換性のあるサーバーを用意してください。

- [Mankai Sync](https://github.com/mankai-app/sync)：`config.json` でユーザーアカウントを設定する同期専用サーバー。
- [Mankai Server](https://github.com/mankai-app/server)：ブックマークと読書記録の同期にも対応する漫画ライブラリサーバー。

選んだリポジトリのセットアップ手順に従ってください。

:::note[サーバー URL]

Mankai Sync では `http://<host>:3000` のようなサーバーのルート URL を使います。Mankai Server では `http://<host>:3000/api` のような API URL を使います。

:::

そのサーバー上のアカウントのユーザー名とパスワードを用意してください。既存のサービスを使う場合は、管理者からこれらの情報を入手してください。

1. **カスタムサーバー**を選び、**サーバURL**に対応する URL を入力します。
2. **設定を保存**をタップします。
3. **認証情報**にユーザー名とパスワードを入力します。
4. **ログイン**をタップします。

### Supabase

Mankai の Supabase プロジェクトを利用できます。接続情報は次のとおりです。

- **プロジェクト URL：** [https://wblemlisleehqgikztlm.supabase.co](https://wblemlisleehqgikztlm.supabase.co)
- **公開可能キー：** `sb_publishable_-Cw5SX-GcpvRd17ikISEMw_Zb4Y5UW1`

:::caution[無料プランのプロジェクトの可用性]
Mankai の Supabase プロジェクトは無料プランを使用しています。正常に動作しない場合があり、いつでも一時停止される可能性があります。
:::

:::tip[独自の Supabase プロジェクト]

独自の Supabase プロジェクトを使う場合は、[Mankai Supabase リポジトリ](https://github.com/mankai-app/supabase)のセットアップ手順に従って、データベースのマイグレーションと OAuth 認証プロバイダーの設定を完了してください。設定済みの別のプロジェクトを使う場合は、管理者からプロジェクト URL と公開可能キーを入手してください。

:::

1. **Supabase** を選び、プロジェクト URL と公開可能キーを入力します。
2. **設定を保存**をタップします。
3. プロジェクトで設定されている認証プロバイダーを選び、**ログイン**をタップします。
4. ログインを完了し、Mankai に戻ります。

## ソースごとの同期対応を確認する

**設定 → ソース**でソースを選ぶか、**設定 → 共有**で共有を選びます。**同期**欄には、ソースの設定と漫画の記録について、個別の対応状況が表示されます。

| 状態                         | 有効の場合                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------- |
| **デバイス間でソースを同期** | 他のデバイスにソースをインストールし、設定を同期します。                     |
| **デバイス間で共有を同期**   | 共有の接続設定を他のデバイスに同期します。                                   |
| **デバイス間で漫画を同期**   | そのソースの漫画のライブラリ登録情報（ブックマーク）と読書記録を同期します。 |

:::note[自動で表示される同期状態]

これらの状態はソースの機能に応じて自動的に表示されます。**無効**の場合は、その下に同期できない理由が表示されます。

:::

## 両方のデバイスを同期する

1. 状態が**有効**になったら、**今すぐ同期**をタップします。
2. 最終同期日時が更新されたことを確認します。
3. もう一方のデバイスでも、同じサービスとアカウントを設定し、**今すぐ同期**をタップします。
4. **設定 → ソース**と**設定 → 共有**で、同期によって復元された対応ソースと共有の接続を確認します。
5. ファイルシステムのソースや、利用可能なダウンロード URL がないソースは手動で追加し、そのデバイスから同じ本を開けることを確認します。
6. 対応する本を開き、**続ける**で前回の続きから再開します。

## ソースを同じものとして識別できるようにする

共有は `.mankai` ファイルを使い、デバイス間で同じソースを識別します。

:::note[ソース ID による同期の制限]

Mankai がそのファイルを書き込めない場合はデバイス専用の ID が使われ、そのソースの記録は同期されません。OPDS はカタログの ID を使いますが、カタログに ID がない場合はデバイス専用の ID になります。組み込みの**ローカルディレクトリ**の記録は、そのデバイス内に保存されます。

共有の表示名が似ていても、ソースの ID が異なれば同じソースにはなりません。デバイス専用の ID により漫画の記録を同期できない場合でも、共有の接続設定は同期できます。また、同期されたブックマークの本を開くには、そのデバイスからソースと本を利用できる必要があります。

:::

## ソースや読書の進み具合が表示されない場合

両方のデバイスで同じアカウントを使い、同期が成功していることを確認します。ソースの**同期**欄で、設定と漫画の同期対応をそれぞれ確認してください。ファイルシステムのソースや、利用可能なダウンロード URL がないソースは手動で追加し、もう一方のデバイスからソースに接続できることを確認します。ブックマークや読書記録だけが表示されない場合は、ソースがデバイス専用の ID を使っていないかも確認してください。接続設定をリセットする前に、[問題が起きたとき](/ja/guides/troubleshooting/)をご覧ください。
