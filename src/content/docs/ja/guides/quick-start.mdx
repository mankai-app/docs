ソースを選び、本を読んで、お気に入りを保存しましょう。Mankai では、おすすめのストリーム型ソースと、手元の本を開くファイル型ソースを使えます。

まだ Mankai をインストールしていない場合は、[インストール](/ja/guides/installation/)で方法を選んでください。

## 1. 基本の画面を知る

Mankai には 4 つのメインタブがあります。

| タブ           | 表示する内容                                     |
| -------------- | ------------------------------------------------ |
| **ホーム**     | ブックマークした作品とダウンロードした本         |
| **ライブラリ** | ソースが提供する作品一覧と検索                   |
| **ファイル**   | ローカルの本、接続した共有、ファイルのインポート |
| **設定**       | リーダーの設定、ソース、同期、読書履歴           |

## 2. ソースを追加する

次の 2 つから選びます。

- **ストリーム型（おすすめ）**：**設定 → ソース**からソースを追加し、外部ライブラリの本を検索して読みます。詳しくは[ソースの追加手順](/ja/guides/sources/#ソースを追加する)をご覧ください。
- **ファイル型**：**ファイル**で本をインポートしたり、ローカルやネットワークの共有に接続したりします。詳しくは[ファイル型ソースの設定](/ja/guides/sources/#ファイル型ソースを追加する)をご覧ください。

## 3. 本を探して読む

1. ソースの本は**ライブラリ**、本ファイルや接続した共有は**ファイル**から開きます。
2. 一覧やフォルダから読みたい作品を探します。ソースが検索に対応している場合は、検索も使えます。
3. 本をタップして詳細を開き、**読む**をタップします。特定のチャプターから読みたい場合は、チャプターグループを開いて読みたいものを選びます。
4. スワイプしてページを進めます。ページの中央付近をタップすると、操作ボタンを表示または非表示にできます。
5. リーダー内の設定ボタンで、**ページ送り**または**連続**を選べます。

## 4. 本を保存して続きから読む

1. 本の詳細に戻り、**ブックマーク**をタップします。
2. **ホーム**を開き、ソースのメニューで**コレクション**を選びます。
3. 本をもう一度開き、読書記録がある場合は**続ける**をタップします。

ブックマークすると、作品をコレクションに保存できます。ソースが新しいチャプターの更新確認に対応している場合は、保存した作品の更新を Mankai が自動で確認します。オフラインで読むためのチャプターのダウンロードは、別の操作です。
