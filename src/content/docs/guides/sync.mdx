Sync is optional and shares supported plugins and their settings, folder connections, bookmarks, and reading progress across devices. Book files and downloaded chapters still need to be available on each device.

You need a compatible HTTP sync service or a configured Supabase project. Use the connection details for your service.

## Choose a sync service

1. Open **Settings → Sync**.
2. Choose a **Sync Engine**. Leave it at **None** if you do not need sync.
3. Complete the appropriate setup below.

### iCloud (coming soon)

iCloud sync is not available yet. Use HTTP or Supabase to sync across devices.

### HTTP

Before using HTTP sync, set up a compatible server using either of these repositories:

- [Mankai Sync](https://github.com/mankai-app/sync): A dedicated sync server with an admin page for managing users.
- [Mankai Server](https://github.com/mankai-app/server): A manga library server that also supports bookmarks and reading progress sync.

Follow the setup instructions in your chosen repository. Use the server's API URL (ending in `/api` for these servers) and the credentials for an account on that server. If you use an existing service, ask its administrator for these details.

1. Select **HTTP** and enter your service's API URL in **Server URL**.
2. Tap **Save Configuration**.
3. Enter your username and password under **Credentials**.
4. Tap **Log In**.

## Check what each source can sync

Open **Settings → Plugins** and select a plugin, or **Settings → Folders** and select a folder. The **Sync** section shows separate statuses for the source's settings and its manga records:

| Status                         | When Enabled                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------- |
| **Sync plugin across devices** | Installs the plugin and syncs its settings on your other devices.                  |
| **Sync folder across devices** | Syncs the folder's connection settings to your other devices.                      |
| **Sync manga across devices**  | Syncs library entries (bookmarks) and reading progress for manga from that source. |

These are automatic capability indicators. If a status is **Disabled**, the explanation below it tells you why that part cannot sync.

## Sync both devices

1. Once the status is **Active**, tap **Sync Now**.
2. Check that the last sync time updates successfully.
3. Configure the same service and account on your other device, then tap **Sync Now** there too.
4. Check **Settings → Plugins** and **Settings → Folders** for the supported plugins and folder connections restored by sync.
5. Add any File System sources or plugins without a usable download URL manually, and confirm that the other device can open the same books.
6. Open a supported book and tap **Continue** to pick up where you left off.

## Keep source identities consistent

Folder sources use a `.mankai` file to identify the same source across devices. If Mankai cannot write that file, the source uses a local identity and its bookmarks and reading progress do not sync. OPDS uses the catalog's ID and falls back to a local identity if the catalog has none. The built-in **Local Directory** keeps its bookmarks and reading progress on that device.

Matching folder names alone do not make two sources the same. Their source IDs must also match. A folder can sync its connection settings even when a local identity prevents its manga records from syncing. A synced bookmark also needs its source and book to be available on the other device before you can open it.

## When a source or reading progress does not appear

Confirm that both devices use the same account and show a successful sync. Check the source's **Sync** section for both settings sync and manga sync support. Add File System sources and plugins without a usable download URL manually, and make sure the source is reachable on the other device. If only bookmarks or progress are missing, check whether the source uses a local identity. Read [Troubleshooting](/guides/troubleshooting/) before resetting your connection settings.
