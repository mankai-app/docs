## App Store

**Paid · Coming soon.** Mankai will be available on the App Store.

## Sideload

**Free.** Download the IPA file from the [latest release](https://github.com/mankai-app/mankai/releases/latest) for sideloading.

AltStore is one option for sideloading. See the [AltStore FAQ](https://faq.altstore.io) for setup and installation instructions.

## Build from source

**Free.** Build Mankai yourself using Xcode on a Mac.

1. Clone the [Mankai repository](https://github.com/mankai-app/mankai) or download its source code.
2. Open `mankai.xcodeproj` in Xcode and let it resolve the Swift package dependencies.
3. In **Signing & Capabilities**, select your development team for the app and thumbnail extension targets. Use unique bundle identifiers for your own build if needed.
4. Select the **mankai** scheme and your connected iPhone or iPad, then choose **Run** to build and install the app.

Once Mankai is installed, continue with [Quick start](/guides/quick-start/) to import your first book.
