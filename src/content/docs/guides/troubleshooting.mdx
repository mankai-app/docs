title: Troubleshooting
description: Resolve common problems with imports, sources, reading controls, downloads, and sync.
---

Start with the screen where the problem appears. The steps below help identify whether the book, its source, or a setting needs attention.

## A file cannot be imported

1. Check that the file is CBZ, CBR, EPUB, PDF, or MMA.
2. Confirm that the file can be accessed in Files and has finished downloading from its storage provider.
3. Open **Files → Imports**, select the file again, and check **Import To**.
4. Try **Local Directory** to check whether the original destination was the problem.
5. If an error appears, save the message so you can describe what failed.

:::note[File extensions do not convert books]

Changing a filename extension does not convert a book.

:::

## A source does not connect

Check the URL or host, required credentials, and network connection. A server on your home network must be reachable from the device. For a local folder, confirm that the location still exists and is available in Files.

Open the source from **Files** to try again. Swipe its row to edit the connection when the address or account has changed. See [Add books and sources](/guides/sources/) for the fields each source requires.

## Library or Home looks empty

**Library** shows lists provided by sources. Add and configure a source in **Settings → Sources** if you want source content. Search only appears when an available source supports it.

**Home → Collections** contains bookmarks. Open a book's details and tap **Bookmark**, then check the source and status filters on Home. Imported book files are available under **Files**, even if you have not bookmarked them.

## Pages move in the wrong direction

1. Tap the center of a reading page to show the controls.
2. Open the reader settings menu and check the mode and reading direction.
3. Check **Tap Navigation** if tapping the page turns it unexpectedly.
4. Open **Settings → Reader** to review defaults and whether Mankai respects the book's reading direction.

## A chapter or download fails

Check whether the source is reachable. Use the chapter's retry action if loading failed, or tap the download arrow on **Home** and tap the retry button for a failed download task. Wait for downloads to finish before reading offline.

:::note[Bookmarks and offline reading]

A bookmark alone does not make a chapter available offline. Choose **Downloads** in the source menu on **Home** to find downloaded content. The download action appears only for sources that support it.

:::

## Sync does not restore a book

Check the account and sync status on both devices. Sync shares supported sources and their settings, share connections, bookmarks, and reading progress.

:::note[Book files and downloads]

Book files and downloaded chapters must still be available on the other device.

:::

Open the source in **Settings → Sources** or **Settings → Shares** and check its **Sync** statuses. Settings sync and manga sync are separate capabilities. Add File System sources and sources without a usable download URL manually on each device, and confirm that network sources are reachable.

:::note[Source identity limits]

If a source uses a local identity instead of a stable source ID, its bookmarks and reading progress do not sync. See [Sync across devices](/guides/sync/) for source identity requirements.

:::

## Describe a problem clearly

When asking your source provider or the app maintainer for help, include the device, app version, source type, steps you tried, and the exact error message. If you attach a screenshot, hide passwords, access keys, and private server details.
