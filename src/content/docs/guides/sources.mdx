Mankai supports two main source types:

| Source type                    | How it works                                                                    | Where to use it                                          |
| ------------------------------ | ------------------------------------------------------------------------------- | -------------------------------------------------------- |
| **Stream-based (recommended)** | A required content plugin connects Mankai to an external library.               | Add it in **Settings → Plugins**, then open **Library**. |
| **File-based**                 | Open supported book files from local folders, network shares, or OPDS catalogs. | Open **Files** to connect a share or import files.       |

## Stream-based sources (recommended)

A stream-based source **requires a content plugin**. This is the recommended approach when a compatible plugin is available: you can browse, search, and read directly from an external library, and automatically check saved titles for new chapters when the plugin supports updates. Available features depend on the plugin and library. See [Collections and downloads](/guides/library/) for saving titles and reading offline.

### Add a content plugin

1. Open **Settings → Plugins** and tap the **+** button.
2. In **Add Plugin**, choose the type your provider specifies: **File System** under **Local**, or **JavaScript** or **HTTP** under **Remote**. This opens a separate configuration screen.
3. For **JavaScript**, enter the supplied URL. If you were given a JSON definition, enable **Use JSON** and paste it there.
4. For **HTTP**, enter the supplied plugin URL. For **File System**, tap **Select Folder**, choose the plugin folder supplied by your provider, and set **Read-Only** if you want to prevent editing.
5. Tap **Add**. Return to **Library** to explore the lists and search features the plugin supports.

A File System plugin expects a structured Mankai library. For an ordinary folder of book files, use **Files → Add Files**. Available search, update, chapter, and download actions depend on the plugin and library.

## File-based sources

File-based sources let you read book files you manage yourself, including CBZ, CBR, EPUB, PDF, and MMA. Connect a local filesystem folder or a network share through SMB, SFTP, NFS, or WebDAV. You can also connect an OPDS catalog to open supported book files or stream pages when available. MMA files are not supported through OPDS. Ordinary file-based sources do not require a content plugin. Open them from **Files**.

**MMA (`.mma`)** stands for Mankai Manga Archive. It packages book metadata, chapter groups, and page images in a ZIP archive. For the archive structure and metadata, see the [MMA format reference](/api/mma-format/).

### Import a book file

1. Open **Files** and tap the **Imports** button, shown as an arrow entering a tray.
2. Tap **Select Files** and choose a book in Files. Supported book formats include CBZ, CBR, EPUB, PDF, and MMA.
3. Under **Import To**, set **Share** to **Local Directory** for a copy stored inside Mankai. Other destinations appear when you have added a share that supports imports.
4. Tap **Import**. Mankai opens the destination's imports folder when the import succeeds.

### Connect a local folder

1. Open **Files → Add Files**.
2. Under **Local Shares**, tap **File System** to open its configuration screen. Add a **Display Name** if you want one.
3. Tap **Select Folder** and choose the folder in the system picker.
4. Tap **Add**, then open the new share in **Files**.
5. Open a subfolder or tap a supported book to see its details.

Connecting a folder lets Mankai browse that location. Use **Imports** to copy selected files into Mankai or another source that supports imports.

### Connect a network share

1. Open **Files → Add Files** and choose **SMB**, **SFTP**, **NFS**, or **WebDAV** under **Remote Shares**.
2. Enter the connection details supplied by your server administrator.
3. Follow the steps for your source type below.

| Source     | Details to enter                                   | Finish                                                                |
| ---------- | -------------------------------------------------- | --------------------------------------------------------------------- |
| **SMB**    | Host, port, and any required username and password | Tap **Select Share**, choose a share if prompted, then tap **Add**    |
| **SFTP**   | Host, port, username, and password                 | Tap **Add**                                                           |
| **NFS**    | Host                                               | Tap **Select Export**, choose an export if prompted, then tap **Add** |
| **WebDAV** | Server URL and any required username and password  | Tap **Add**                                                           |

If SMB finds only one share or NFS finds only one export, Mankai adds it automatically. Open the new source from **Files**. Keep the network source reachable while browsing and reading its books.

### Connect an OPDS catalog

OPDS catalogs are available from **Files**. Mankai can open supported book files or stream pages when the catalog supports page streaming.

1. Open **Files → Add Files** and tap **OPDS** under **Catalogs**.
2. Enter the catalog URL and any required username and password.
3. Tap **Add**, then open the catalog from **Files**.

## Manage a connection

Swipe a share in **Files** to edit or remove its connection, or manage it in **Settings → Shares**. Manage installed content plugins in **Settings → Plugins**.

To sync supported plugins, share connections, bookmarks, and reading progress between devices, see [Sync across devices](/guides/sync/). For connection problems, see [Troubleshooting](/guides/troubleshooting/).
