選擇來源，開始閱讀並收藏喜歡的書籍。Mankai 支援建議的串流式來源，也能透過檔案式來源打開自己的書籍。

如果尚未安裝 Mankai，請先在[安裝指南](/zh-tw/guides/installation/)中選擇一種方式。

## 1. 認識主要頁面

Mankai 有四個主要分頁。

| 分頁     | 主要內容                           |
| -------- | ---------------------------------- |
| **首頁** | 已收藏的作品和已下載的書籍         |
| **書庫** | 來源提供的作品清單和搜尋功能       |
| **檔案** | 本機書籍、已連接的共用和檔案匯入   |
| **設定** | 閱讀偏好、來源、同步和閱讀歷史記錄 |

## 2. 新增來源

選擇以下兩種方式之一：

- **串流式（建議）**：在**設定 → 來源**新增來源，搜尋和閱讀外部書庫。請參考詳細的[來源設定步驟](/zh-tw/guides/sources/#新增來源)。
- **檔案式**：在**檔案**中匯入書籍檔案，或連接本機與網路共用。請參考詳細的[檔案式來源設定](/zh-tw/guides/sources/#檔案式來源)。

## 3. 尋找書籍並閱讀

### 找一本書

1. 打開**書庫**查看來源提供的作品，或打開**檔案**查看書籍檔案和已連接的共用。
2. 從清單或資料夾中選擇作品。如果來源支援搜尋，也可以搜尋想讀的書籍。
3. 點一下書籍，打開包含簡介、章節清單和閱讀按鈕的詳細資訊頁面。

### 開始閱讀

1. 點一下**閱讀**開始閱讀。若要選擇指定章節，展開章節組後點一下所需章節。
2. 在**分頁**模式中滑動翻頁，或在**連續**模式中捲動瀏覽頁面。
3. 點一下頁面中央附近，可顯示或隱藏閱讀控制按鈕。
4. 使用閱讀器中的設定按鈕，選擇**分頁**或**連續**閱讀，並調整閱讀排版。

## 4. 方便下次繼續閱讀

1. 返回書籍詳細資訊，點一下**收藏**。
2. 打開**首頁**，在來源選單中選擇**收藏**。
3. 再次打開書籍，如果已有閱讀進度，點一下**繼續**。

收藏會將作品保留在收藏清單中。若來源支援更新檢查，Mankai 也會自動檢查已收藏作品是否有新章節。要離線閱讀，請從支援下載的來源另外下載章節。
