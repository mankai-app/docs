同步是可選功能，可在裝置間共享受支援的外掛模組及其設定、資料夾連線、收藏和閱讀進度。書籍檔案和已下載的章節仍需在每台裝置上分別準備。

你需要相容的 HTTP 同步服務，或已經設定好的 Supabase 專案。請使用對應服務的連線資訊。

## 選擇同步服務

1. 打開**設定 → 同步**。
2. 選擇**同步引擎**。如果不需要同步，請保留為**無**。
3. 按照下方對應的步驟完成設定。

### iCloud（即將推出）

iCloud 同步即將推出，目前尚不可用。現在請使用 HTTP 或 Supabase 在裝置間同步。

### HTTP

使用 HTTP 同步之前，請先透過以下任一儲存庫架設相容的伺服器：

- [Mankai Sync](https://github.com/mankai-app/sync)：專用同步伺服器，提供用於管理使用者的管理頁面。
- [Mankai Server](https://github.com/mankai-app/server)：漫畫書庫伺服器，同時支援收藏和閱讀進度同步。

按照所選儲存庫的設定說明完成部署。請使用伺服器的 API 網址（這兩個伺服器均以 `/api` 結尾）和該伺服器上的帳戶憑證。如果使用既有服務，請向管理員索取這些資訊。

1. 選擇 **HTTP**，在**伺服器網址**中輸入同步服務的 API 網址。
2. 點一下**儲存設定**。
3. 在**憑證**中輸入使用者名稱和密碼。
4. 點一下**登入**。

1. 選擇 **Supabase**，輸入專案網址和可發布金鑰。

## 檢查每個內容源的同步支援

打開**設定 → 外掛模組**並選擇外掛模組，或打開**設定 → 資料夾**並選擇資料夾。**同步**區域分別顯示內容源設定和漫畫記錄的同步狀態：

| 狀態                 | 顯示為已啟用時                                   |
| -------------------- | ------------------------------------------------ |
| **跨裝置同步插件**   | 在其他裝置上安裝外掛模組，並同步其設定。         |
| **跨裝置同步資料夾** | 將資料夾的連線設定同步到其他裝置。               |
| **跨裝置同步漫畫**   | 同步該內容源中漫畫的書庫記錄（收藏）和閱讀進度。 |

這些狀態會根據內容源的功能自動顯示。如果狀態為**已停用**，下方會說明無法同步的原因。

## 同步兩台裝置

1. 狀態顯示為**啟用中**後，點一下**立即同步**。
2. 確認上次同步時間已成功更新。
3. 在另一台裝置上設定相同的服務和帳戶，然後也點一下**立即同步**。
4. 打開**設定 → 外掛模組**和**設定 → 資料夾**，檢查同步還原的受支援外掛模組和資料夾連線。
5. 手動新增檔案系統內容源或沒有可用下載網址的外掛模組，並確認另一台裝置能夠打開相同的書籍。
6. 打開受支援的書籍，並使用**繼續**從上次的位置繼續閱讀。

## 保持內容源識別碼一致

資料夾內容源使用 `.mankai` 檔案在不同裝置上識別同一個內容源。如果 Mankai 無法寫入該檔案，內容源會使用本機識別碼，其記錄不會同步。OPDS 使用目錄的 ID，如果目錄沒有 ID，則改用本機識別碼。內建的**本機目錄**始終將記錄保留在本機。

資料夾名稱相似並不代表內容源識別碼相同，內容源 ID 也必須一致。即使本機識別碼導致漫畫記錄無法同步，資料夾的連線設定仍可同步。要打開同步後的收藏，另一台裝置必須能夠存取對應的內容源和書籍。

## 內容源或閱讀進度沒有出現時

確認兩台裝置使用相同帳戶，並顯示同步成功。在內容源的**同步**區域，分別檢查設定同步和漫畫同步的支援狀態。請手動新增檔案系統內容源及沒有可用下載網址的外掛模組，並確認另一台裝置能夠存取內容源。如果只有收藏或進度缺失，請檢查內容源是否使用本機識別碼。在重設連線設定之前，先閱讀[故障排查](/zh-tw/guides/troubleshooting/)。
