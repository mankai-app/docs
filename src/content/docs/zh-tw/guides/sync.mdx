同步是可選功能，可在裝置間共享受支援的來源及其設定、共用連線、收藏和閱讀進度。

:::note[書籍檔案與下載]

書籍檔案和已下載的章節仍需在每台裝置上分別準備。

:::

你需要相容的自訂伺服器，或已經設定好的 Supabase 專案。請使用對應服務的連線資訊。

## 選擇同步服務

1. 打開**設定 → 同步**。
2. 在**同步引擎**中選擇**自訂伺服器**或 **Supabase**。如果不需要同步，請保留為**無**。
3. 按照下方對應的步驟完成設定。

### iCloud（即將推出）

:::note[iCloud 可用性]

iCloud 同步即將推出，目前尚不可用。現在請使用自訂伺服器或 Supabase 在裝置間同步。

:::

### 自訂伺服器

使用自訂伺服器同步之前，請先透過以下任一儲存庫架設相容的伺服器：

- [Mankai Sync](https://github.com/mankai-app/sync)：專用同步伺服器，在 `config.json` 中設定使用者帳戶。
- [Mankai Server](https://github.com/mankai-app/server)：漫畫書庫伺服器，同時支援收藏和閱讀進度同步。

按照所選儲存庫的設定說明完成部署。

:::note[伺服器網址]

Mankai Sync 使用伺服器的根網址，例如 `http://<host>:3000`。Mankai Server 使用 API 網址，例如 `http://<host>:3000/api`。

:::

請準備該伺服器上帳戶的使用者名稱和密碼。如果使用既有服務，請向管理員索取這些資訊。

1. 選擇**自訂伺服器**，在**伺服器網址**中輸入對應的網址。
2. 點一下**儲存設定**。
3. 在**憑證**中輸入使用者名稱和密碼。
4. 點一下**登入**。

## 檢查每個來源的同步支援

打開**設定 → 來源**並選擇來源，或打開**設定 → 共用**並選擇共用。**同步**區域分別顯示來源設定和漫畫記錄的同步狀態：

| 狀態               | 顯示為已啟用時                                 |
| ------------------ | ---------------------------------------------- |
| **跨裝置同步來源** | 在其他裝置上安裝來源，並同步其設定。           |
| **跨裝置同步共用** | 將共用的連線設定同步到其他裝置。               |
| **跨裝置同步漫畫** | 同步該來源中漫畫的書庫記錄（收藏）和閱讀進度。 |

:::note[自動同步狀態]

這些狀態會根據來源的功能自動顯示。如果狀態為**已停用**，下方會說明無法同步的原因。

:::

## 同步兩台裝置

1. 狀態顯示為**啟用中**後，點一下**立即同步**。
2. 確認上次同步時間已成功更新。
3. 在另一台裝置上設定相同的服務和帳戶，然後也點一下**立即同步**。
4. 打開**設定 → 來源**和**設定 → 共用**，檢查同步還原的受支援來源和共用連線。
5. 手動新增檔案系統來源或沒有可用下載網址的來源，並確認另一台裝置能夠打開相同的書籍。
6. 打開受支援的書籍，並使用**繼續**從上次的位置繼續閱讀。

## 保持來源識別碼一致

共用使用 `.mankai` 檔案在不同裝置上識別同一個來源。

:::note[來源識別碼限制]

如果 Mankai 無法寫入該檔案，來源會使用本機識別碼，其記錄不會同步。OPDS 使用目錄的 ID，如果目錄沒有 ID，則改用本機識別碼。內建的**本機目錄**始終將記錄保留在本機。

共用名稱相似並不代表來源識別碼相同，來源 ID 也必須一致。即使本機識別碼導致漫畫記錄無法同步，共用的連線設定仍可同步。要打開同步後的收藏，另一台裝置必須能夠存取對應的來源和書籍。

:::

## 來源或閱讀進度沒有出現時

確認兩台裝置使用相同帳戶，並顯示同步成功。在來源的**同步**區域，分別檢查設定同步和漫畫同步的支援狀態。請手動新增檔案系統來源及沒有可用下載網址的來源，並確認另一台裝置能夠存取來源。如果只有收藏或進度缺失，請檢查來源是否使用本機識別碼。在重設連線設定之前，先閱讀[故障排查](/zh-tw/guides/troubleshooting/)。
