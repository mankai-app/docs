同步是可選功能，會傳輸受支援的收藏和閱讀進度。書籍檔案、已下載的章節和內容源設定需要在每台裝置上分別準備。

你需要相容的 HTTP 同步服務，或已經設定好的 Supabase 專案。請使用對應服務的連線資訊。

## 選擇同步服務

1. 打開**設定 → 同步**。
2. 選擇**同步引擎**。如果不需要同步，請保留為**無**。
3. 按照下方對應的步驟完成設定。

### iCloud（即將推出）

iCloud 同步即將推出，目前尚不可用。現在請使用 HTTP 或 Supabase 在裝置間同步。

### HTTP

使用 HTTP 同步之前，請先透過以下任一儲存庫架設相容的伺服器：

- [Mankai Sync](https://github.com/mankai-app/sync)：專用同步伺服器，提供用於管理使用者的管理頁面。
- [Mankai Server](https://github.com/mankai-app/server)：漫畫書庫伺服器，同時支援收藏和閱讀進度同步。

按照所選儲存庫的設定說明完成部署。請使用伺服器的 API 網址（這兩個伺服器均以 `/api` 結尾）和該伺服器上的帳戶憑證。如果使用既有服務，請向管理員索取這些資訊。

1. 選擇 **HTTP**，在**伺服器網址**中輸入同步服務的 API 網址。
2. 點一下**儲存設定**。
3. 在**憑證**中輸入使用者名稱和密碼。
4. 點一下**登入**。

### Supabase

使用 Supabase 同步之前，請先建立 Supabase 專案，並按照 [Mankai Supabase 儲存庫](https://github.com/mankai-app/supabase)中的設定說明套用資料庫遷移、部署 Edge Functions，以及設定 OAuth 登入提供者。如果使用既有且設定完成的專案，請向管理員索取專案網址和金鑰。

1. 選擇 **Supabase**，輸入已設定專案的網址和金鑰。
2. 點一下**儲存設定**。
3. 選擇該專案設定的登入提供者，再點一下**登入**。
4. 完成登入流程並返回 Mankai。

## 同步兩台裝置

1. 狀態顯示為**啟用中**後，點一下**立即同步**。
2. 確認上次同步時間已成功更新。
3. 在另一台裝置上設定相同的服務和帳戶。
4. 在另一台裝置上新增相同的書籍內容源，然後也點一下**立即同步**。
5. 打開受支援的書籍，並使用**繼續**從上次的位置繼續閱讀。

## 保持內容源識別碼一致

資料夾內容源使用 `.mankai` 檔案在不同裝置上識別同一個內容源。如果 Mankai 無法寫入該檔案，內容源會使用本機識別碼，其記錄不會同步。OPDS 使用目錄的 ID，如果目錄沒有 ID，則改用本機識別碼。內建的**本機目錄**始終將記錄保留在本機。

資料夾名稱相似並不代表內容源識別碼相同。要打開同步後的收藏，另一台裝置必須能夠存取對應的內容源。

## 閱讀進度沒有出現時

確認兩台裝置使用相同帳戶、都能打開同一內容源，並顯示同步成功。檢查內容源是否使用本機識別碼。在重設連線設定之前，先閱讀[故障排查](/zh-tw/guides/troubleshooting/)。
