打開**設定 → 圖片處理**，選擇 Mankai 如何處理閱讀器中的頁面。你可以啟用處理器、調整設定，並排列執行順序。

## 選擇本機處理器

本機處理器在裝置上執行。初始狀態下，**4× Real-ESRGAN 圖片放大**處於停用狀態，**縮小圖片**已啟用。

| 處理器                      | 用途                                                                               | 設定                                                                                                   |
| --------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **4× Real-ESRGAN 圖片放大** | 使用 realesr-animevideov3 模型放大低解析度頁面。已足以配合螢幕顯示的圖片不會放大。 | **圖片放大敏感度**決定哪些圖片會放大。提高敏感度會讓更大的圖片也參與放大，並使用更多運算資源和記憶體。 |
| **縮小圖片**                | 降低圖片解析度以減少記憶體用量。停用後保留完整解析度，但會使用更多記憶體。         | **節省記憶體**提供**低**、**平衡**和**高**。節省越多，圖片解析度越低。                                 |
| **單色調**                  | 在保持線條清晰和對比自然的同時，為頁面加入自訂色調。                               | 選擇**色調顏色**並調整**色調強度**。                                                                   |

1. 打開**設定 → 圖片處理**並點一下 **+**。
2. 在**本機**下選擇要新增的處理器。新處理器會自動啟用。
3. 點一下處理器所在列，打開**設定**並調整可用項目。變更會自動儲存。
4. 使用處理器旁的開關啟用或停用它。停用不會移除其設定。

建議先將**圖片放大敏感度**和**節省記憶體**設為**平衡**。使用圖片放大時，請在它後面啟用**縮小圖片**，以控制最終圖片尺寸和記憶體用量。

## 變更處理順序

已啟用的處理器從上到下依次執行。每個處理器接收上一個處理器輸出的圖片，因此變更順序可能改變結果。

1. 在**圖片處理**中點一下**編輯**。
2. 拖曳排序控制點，調整處理器順序。
3. 完成後點一下**完成**。

如果想先放大再節省記憶體，請將**4× Real-ESRGAN 圖片放大**放在**縮小圖片**上方。若想調整最終頁面的顏色，可以在它們後面新增**單色調**。

## 新增遠端圖片處理器

遠端處理器會將閱讀器圖片傳送到伺服器，並在閱讀器中顯示傳回的圖片。你需要相容於 Mankai 的圖片處理服務，以及 iPhone 或 iPad 能存取的伺服器網址。

1. 打開**設定 → 圖片處理**並點一下 **+**。
2. 在**遠端**下選擇**遠端圖片處理器**。
3. 在**伺服器網址**中輸入服務的基礎網址，然後點一下**新增**。Mankai 會讀取伺服器名稱和設定欄位。
4. 點一下新處理器所在列，調整**設定**。如果伺服器要求認證，請輸入提供的**使用者名稱**和**密碼**。
5. 確認開關已啟用，並將它放在所需的處理位置。

請輸入類似 `https://images.example.com/mankai` 的基礎網址，而不是 `/process` 端點。使用家庭網路上的伺服器時，閱讀過程中裝置必須能存取它。只有本機處理器可以在不連接處理伺服器的情況下執行。

遠端處理器接收其所在處理位置的圖片。例如，將它放在**單色調**後面，會把已調整色調的圖片傳送到伺服器。可用設定和效果取決於服務。

如果你要開發相容的伺服器，請閱讀[圖片處理器 API](/zh-tw/api/image-processors/)。

## 重設或移除處理器

點一下處理器所在列，再依序點一下**重設設定**和**重設**，即可恢復預設設定。對於需要認證的遠端處理器，這也會清除使用者名稱和密碼。

若要移除處理器，請滑動其所在列並確認**移除**，或在設定頁面使用**移除**。如果只想暫停效果並保留設定，請關閉開關。

## 處理緩慢或沒有效果時

- 確認處理器已啟用，並檢查它在清單中的位置。
- 圖片放大會略過已足以配合螢幕顯示的圖片。提高**圖片放大敏感度**之前，先嘗試低解析度頁面。
- 如果放大處理較慢，請降低**圖片放大敏感度**或停用處理器。保持**縮小圖片**啟用，以減少記憶體用量。
- 對於遠端處理器，請檢查基礎網址、伺服器狀態、網路連線和所需憑證。

圖片放大或遠端處理完成前，閱讀器可能先顯示原始頁面。如果處理失敗，Mankai 會保留原始圖片供你閱讀。

頁面排版和操作方式請參閱[閱讀與閱讀器設定](/zh-tw/guides/reading/)。
