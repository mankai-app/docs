Mankai 有兩種主要來源：**檔案式**來源讓你從不同檔案系統和網路儲存讀取書籍檔案。**串流式**來源連接外部書庫。建議使用串流式來源，直接瀏覽、搜尋和閱讀外部書庫，並在來源支援時自動檢查更新。

| 方式               | 適用內容                                                            | 使用位置                              |
| ------------------ | ------------------------------------------------------------------- | ------------------------------------- |
| **串流式（建議）** | 來源提供的外部書庫，可依支援情況瀏覽、搜尋、閱讀並自動檢查更新      | 在**設定 → 來源**新增，從**書庫**使用 |
| **檔案式**         | 本機檔案系統、SMB、SFTP、NFS、WebDAV 或 OPDS 目錄提供的支援書籍檔案 | **檔案**                              |

OPDS 目錄則透過**檔案 → 加入檔案**連接，詳見下方的目錄設定。

## 串流式來源（建議）

串流式來源讓 Mankai 能從外部書庫取得作品清單、搜尋書籍、讀取章節，並在支援時自動檢查書籍或章節更新。請使用提供者給你的來源網址、JSON 定義或結構化書庫。

### 新增來源

你可以手動設定來源，也可以使用提供者的新增來源連結或 QR 碼。

#### 手動新增

**本機來源**包含**檔案系統**。**遠端來源**包含 **JavaScript** 和 **Mankai 相容**。**整合**包含 **Komga 伺服器**、**Kavita 伺服器**和 **Suwayomi 伺服器**。

1. 打開**設定 → 來源**，點一下 **+** 按鈕。
2. 在**新增來源**的對應分組中選擇提供者指定的類型，打開設定頁面。
3. 按照下表填寫對應來源類型的資訊。
4. 點一下**新增**。返回**書庫**，瀏覽來源支援的清單和搜尋功能。

| 來源                | 設定內容                                                                                                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **檔案系統**        | 點一下**選擇資料夾**，選擇提供者按規定結構組織的書庫資料夾。啟用**唯讀**可防止編輯。                                                               |
| **JavaScript**      | 輸入提供的網址，或啟用**使用 JSON**並貼上提供的 JSON 定義。                                                                                        |
| **Mankai 相容**     | 輸入伺服器 API 網址，以及所需的使用者名稱和密碼。                                                                                                  |
| **Komga 伺服器**    | 輸入伺服器網址，並使用 API 金鑰或 Komga 使用者名稱和密碼。                                                                                         |
| **Kavita 伺服器**   | 輸入伺服器網址，並使用 Kavita 使用者名稱和密碼，或將 Kavita **使用者設定 → 第三方用戶端**中的驗證金鑰填入 **API 金鑰**欄位。                       |
| **Suwayomi 伺服器** | 輸入伺服器網址，並將**驗證模式**設為與伺服器一致的**無**、**基本驗證**、**簡易登入**或**介面登入**。除非選擇**無**，否則還需輸入使用者名稱和密碼。 |

搜尋、自動檢查更新、章節和下載功能是否可用，取決於來源的支援情況。

:::note[來源說明]

- **檔案系統：**需要符合 Mankai 結構的書庫。普通書籍資料夾請使用**檔案 → 加入檔案**。
- **Kavita：**顯示圖片、封存和 PDF 格式的系列，不顯示 EPUB 系列。
- **Suwayomi：**顯示已加入 Suwayomi 伺服器書庫的作品。

:::

#### 使用新增來源連結或 QR 碼

打開提供者的 **Add to Mankai** 連結，或使用**設定 → 來源 → +**中的 **QR 碼**按鈕掃描代碼、選擇 QR 碼圖片或貼上連結。確認來源後點一下**新增**。

提供者可參閱[新增來源連結參考](/zh-tw/api/source-links/)建立連結。

## 檔案式來源

檔案式來源適合直接打開 CBZ、CBR、EPUB、PDF 和 MMA 書籍檔案。使用**檔案**存取本機檔案系統，或透過 SMB、SFTP、NFS、WebDAV 連接不同的網路共用和儲存位置。也可以連接 OPDS 目錄，開啟支援的書籍檔案，或在目錄支援時透過頁面串流閱讀。普通書籍資料夾可以直接從**檔案**打開。

:::note[OPDS 格式支援]

不支援透過 OPDS 讀取 MMA 檔案。

:::

**MMA（`.mma`）** 是 Mankai Manga Archive 的縮寫，以 ZIP 封存檔打包書籍中繼資料、章節群組和頁面圖片。如需瞭解封存檔結構與中繼資料，請參閱 [MMA 格式參考](/zh-tw/api/mma-format/)。

### 匯入書籍檔案

1. 打開**檔案**，點一下**匯入**按鈕，圖示是指向托盤的箭頭。
2. 點一下**選擇檔案**，在「檔案」中選擇一本書。支援 CBZ、CBR、EPUB、PDF 和 MMA 格式。
3. 在**匯入至**的**共用**中選擇**本機目錄**，將副本儲存在 Mankai 內。如果已經新增支援匯入的共用，也會顯示其他目標位置。
4. 點一下**匯入**。匯入成功後，Mankai 會打開目標位置中的匯入資料夾。

### 連接本機資料夾

1. 打開**檔案 → 加入檔案**。
2. 點一下**本機共用**下的**檔案系統**，打開設定頁面，也可以填寫**顯示名稱**。
3. 點一下**選擇資料夾**，在系統選擇器中選擇資料夾。
4. 點一下**新增**，然後在**檔案**中打開新共用。
5. 打開子資料夾，或點一下支援的書籍檔案查看詳細資訊。

連接資料夾後，Mankai 就能瀏覽該位置。如果想將選定檔案複製到某個匯入目標，請使用**匯入**。

### 連接網路儲存

1. 打開**檔案 → 加入檔案**，在**遠端共用**下選擇 **SMB**、**SFTP**、**NFS** 或 **WebDAV**。
2. 輸入伺服器管理員提供的連線資訊。
3. 按照下表完成對應類型的操作。

| 來源       | 需要填寫的資訊                           | 完成步驟                                                     |
| ---------- | ---------------------------------------- | ------------------------------------------------------------ |
| **SMB**    | 主機、連接埠，以及必要的使用者名稱和密碼 | 點一下**選擇共用**，按提示選擇共用位置，再點一下**新增**     |
| **SFTP**   | 主機、連接埠、使用者名稱和密碼           | 點一下**新增**                                               |
| **NFS**    | 主機                                     | 點一下**選擇匯出目錄**，按提示選擇匯出目錄，再點一下**新增** |
| **WebDAV** | 伺服器網址，以及必要的使用者名稱和密碼   | 點一下**新增**                                               |

:::note[自動選擇共用]

如果 SMB 只找到一個共用位置，或 NFS 只找到一個匯出目錄，Mankai 會自動新增。

:::

然後從**檔案**打開新來源。瀏覽和閱讀網路書籍時，請保持來源可連線。

### 連接 OPDS 目錄

OPDS 目錄透過**檔案**中的獨立目錄連接存取，無需在**書庫**中另外新增來源。目錄可提供支援的書籍檔案。若支援頁面串流，也能直接串流閱讀。

1. 打開**檔案 → 加入檔案**，點一下**目錄**下的 **OPDS**。
2. 輸入目錄網址，以及必要的使用者名稱和密碼。
3. 點一下**新增**，然後從**檔案**打開新目錄。

瀏覽和閱讀網路書籍時，請保持來源可連線。

## 管理連接

在**檔案**中滑動共用條目，可編輯或移除連接，也可以打開**設定 → 共用**查看。打開**設定 → 來源**可查看已安裝的來源。

如果希望在不同裝置間同步受支援的來源、共用連線、收藏和閱讀進度，請閱讀[跨裝置同步](/zh-tw/guides/sync/)。如果連線遇到問題，請閱讀[故障排查](/zh-tw/guides/troubleshooting/)。
