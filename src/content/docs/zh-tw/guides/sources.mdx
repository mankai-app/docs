Mankai 有兩種主要內容源：**檔案式**內容源讓你從不同檔案系統和網路儲存讀取書籍檔案。**串流式**內容源透過內容外掛模組連接外部書庫。建議使用串流式內容源，直接瀏覽、搜尋和閱讀外部書庫，並在外掛模組支援時自動檢查更新。

| 方式               | 適用內容                                                            | 使用位置                                  |
| ------------------ | ------------------------------------------------------------------- | ----------------------------------------- |
| **串流式（建議）** | 外掛模組提供的外部書庫，可依支援情況瀏覽、搜尋、閱讀並自動檢查更新  | 在**設定 → 外掛模組**新增，從**書庫**使用 |
| **檔案式**         | 本機檔案系統、SMB、SFTP、NFS、WebDAV 或 OPDS 目錄提供的支援書籍檔案 | **瀏覽**                                  |

OPDS 目錄則透過**瀏覽 → 加入資料夾**連接，詳見下方的目錄設定。

## 串流式內容源（建議）

串流式內容源需要內容外掛模組。外掛模組讓 Mankai 能從外部書庫取得作品清單、搜尋書籍、讀取章節，並在支援時自動檢查書籍或章節更新。請使用提供者給你的外掛模組網址、JSON 定義或結構化書庫。

### 新增內容外掛模組

1. 打開**設定 → 外掛模組**，點一下 **+** 按鈕。
2. 選擇提供者指定的外掛模組類型。
3. 對於 **JavaScript**，輸入提供的網址。如果獲得的是 JSON 定義，請啟用**使用 JSON**並貼上內容。
4. 對於 **HTTP**，輸入提供的外掛模組網址。對於**檔案系統**，選擇提供者按規定結構組織的外掛模組資料夾，並決定是否設為唯讀。
5. 點一下**新增**。返回**書庫**，瀏覽外掛模組支援的清單和搜尋功能。

即使選擇**檔案系統**外掛模組，內容也必須是符合 Mankai 結構的書庫。這與存放普通書籍檔案的資料夾不同。普通資料夾請使用**瀏覽 → 加入資料夾**。搜尋、自動檢查更新、章節和下載功能是否可用，取決於外掛模組的支援情況。

## 檔案式內容源

檔案式內容源適合直接打開 CBZ、CBR、EPUB、PDF 和 MMA 書籍檔案。使用**瀏覽**存取本機檔案系統，或透過 SMB、SFTP、NFS、WebDAV 連接不同的網路共用和儲存位置。也可以連接 OPDS 目錄，開啟支援的書籍檔案，或在目錄支援時透過頁面串流閱讀。不支援透過 OPDS 讀取 MMA 檔案。普通書籍資料夾不需要內容外掛模組。

**MMA（`.mma`）** 是 Mankai Manga Archive 的縮寫，以 ZIP 封存檔打包書籍中繼資料、章節群組和頁面圖片。如需瞭解封存檔結構與中繼資料，請參閱 [MMA 格式參考](/zh-tw/api/mma-format/)。

### 匯入書籍檔案

1. 打開**瀏覽**，點一下**匯入**按鈕，圖示是指向托盤的箭頭。
2. 點一下**選擇檔案**，在「檔案」中選擇一本書。支援 CBZ、CBR、EPUB、PDF 和 MMA 格式。
3. 在**匯入至**中選擇**本機目錄**，將副本儲存在 Mankai 內。如果已經新增支援匯入的內容源，也會顯示其他目標位置。
4. 點一下**匯入**。匯入成功後，Mankai 會打開目標位置中的匯入資料夾。

### 連接本機資料夾

1. 打開**瀏覽 → 加入資料夾**。
2. 將**資料夾類型**設為**檔案系統**，也可以填寫顯示名稱。
3. 點一下**選擇資料夾**，在系統選擇器中選擇資料夾。
4. 點一下**新增**，然後在**瀏覽**中打開新資料夾。
5. 打開子資料夾，或點一下支援的書籍檔案查看詳細資訊。

連接資料夾後，Mankai 就能瀏覽該位置。如果想將選定檔案複製到某個匯入目標，請使用**匯入**。

### 連接網路儲存

1. 打開**瀏覽 → 加入資料夾**，選擇適合的**資料夾類型**。
2. 輸入伺服器管理員提供的連線資訊。
3. 按照下表完成對應類型的操作。

| 內容源     | 需要填寫的資訊                           | 完成步驟                                                     |
| ---------- | ---------------------------------------- | ------------------------------------------------------------ |
| **SMB**    | 主機、連接埠，以及必要的使用者名稱和密碼 | 點一下**選擇共用**，按提示選擇共用位置，再點一下**新增**     |
| **SFTP**   | 主機、連接埠、使用者名稱和密碼           | 點一下**新增**                                               |
| **NFS**    | 主機                                     | 點一下**選擇匯出目錄**，按提示選擇匯出目錄，再點一下**新增** |
| **WebDAV** | 伺服器網址，以及必要的使用者名稱和密碼   | 點一下**新增**                                               |

如果 SMB 只找到一個共用位置，或 NFS 只找到一個匯出目錄，Mankai 會自動新增。然後從**瀏覽**打開新內容源。瀏覽和閱讀網路書籍時，請保持內容源可連線。

### 連接 OPDS 目錄

OPDS 目錄透過**瀏覽**中的獨立目錄連接存取，不需要內容外掛模組。目錄可提供支援的書籍檔案。若支援頁面串流，也能直接串流閱讀。

1. 打開**瀏覽 → 加入資料夾**，將**資料夾類型**設為 **OPDS**。
2. 輸入目錄網址，以及必要的使用者名稱和密碼。
3. 點一下**新增**，然後從**瀏覽**打開新目錄。

瀏覽和閱讀網路書籍時，請保持內容源可連線。

## 管理連接

在**瀏覽**中滑動資料夾條目，可編輯或移除連接，也可以打開**設定 → 資料夾**查看。打開**設定 → 外掛模組**可查看已安裝的內容外掛模組。

如果希望在不同裝置間同步閱讀進度，請閱讀[跨裝置同步](/zh-tw/guides/sync/)。如果連線遇到問題，請閱讀[故障排查](/zh-tw/guides/troubleshooting/)。
