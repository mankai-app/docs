title: 故障排查
description: 解決匯入、來源、閱讀控制、下載和同步的常見問題。
---

從出現問題的頁面開始。以下步驟有助於判斷問題出在書籍、來源還是設定。

## 無法匯入檔案

1. 確認檔案格式為 CBZ、CBR、EPUB、PDF 或 MMA。
2. 確認能在「檔案」中存取該檔案，並且已經從儲存提供者下載完成。
3. 打開**檔案 → 匯入**，重新選擇檔案並檢查**匯入至**。
4. 嘗試選擇**本機目錄**，判斷問題是否來自原目標位置。
5. 如果出現錯誤，請保留錯誤資訊，以便描述失敗原因。

:::note[修改副檔名不會轉換格式]

修改副檔名不會轉換書籍格式。

:::

## 來源無法連接

檢查網址或主機、所需的登入憑證和網路連線。裝置必須能存取家庭網路中的伺服器。對於本機資料夾，請確認該位置仍存在，而且能在「檔案」中存取。

從**檔案**打開來源再試一次。如果地址或帳戶發生變化，可滑動條目來編輯連接。[新增書籍與來源](/zh-tw/guides/sources/)列出了各類來源需要填寫的欄位。

## 書庫或首頁是空的

**書庫**顯示來源提供的清單。如果想閱讀來源內容，請在**設定 → 來源**中新增並設定來源。只有可用來源支援搜尋時，才會顯示搜尋功能。

**首頁 → 收藏**包含已收藏的作品。打開書籍詳細資訊並點一下**收藏**，然後檢查首頁上的來源和狀態篩選項。即使尚未收藏，也能在**檔案**中找到已匯入的書籍檔案。

## 翻頁方向不對

1. 點一下閱讀頁面中央，顯示控制按鈕。
2. 打開閱讀器設定選單，檢查模式和閱讀方向。
3. 如果點一下頁面時出現意外翻頁，請檢查**點一下翻頁**。
4. 打開**設定 → 閱讀器**，查看預設設定，以及 Mankai 是否遵循書籍的閱讀方向。

## 章節載入或下載失敗

檢查來源是否可存取。如果章節載入失敗，請在閱讀器中重試。如果下載失敗，請點一下**首頁**上的下載箭頭，並點一下失敗工作的重試按鈕。等下載完成後再進行離線閱讀。

:::note[收藏與離線閱讀]

僅收藏作品並不能讓章節離線可用。在首頁的來源選單中選擇**下載**，即可尋找已下載的內容。只有支援下載的來源才會顯示下載操作。

:::

## 同步後無法恢復書籍

檢查兩台裝置的帳戶和同步狀態。同步會共享受支援的來源及其設定、共用連線、收藏和閱讀進度。

:::note[書籍檔案與下載]

書籍檔案和已下載的章節仍需在另一台裝置上準備。

:::

在**設定 → 來源**或**設定 → 共用**中打開來源，檢查其**同步**狀態。設定同步和漫畫同步是獨立的功能。請在每台裝置上手動新增檔案系統來源及沒有可用下載網址的來源，並確認網路來源能夠連線。

:::note[來源識別碼限制]

如果來源使用本機識別碼而非穩定的來源識別碼，其收藏和閱讀進度不會同步。關於來源識別碼的要求，請閱讀[跨裝置同步](/zh-tw/guides/sync/)。

:::

## 清楚描述問題

向來源提供者或應用程式維護者尋求幫助時，請提供裝置、應用程式版本、來源類型、已嘗試的步驟和準確的錯誤資訊。如果附上截圖，請隱藏密碼、存取金鑰和私人伺服器資訊。
